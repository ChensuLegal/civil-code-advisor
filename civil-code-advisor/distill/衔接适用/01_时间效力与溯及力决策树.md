## 〇、九部被废止法律对照（溯及判断的「旧法」清单）

《民法典》第1260条自2021年1月1日同时废止下列九部法律。凡「民法典施行前的法律事实」引起、需回溯「当时的法律」者，必落在以下范围：

| 旧法 | 归入民法典的位置 | 时间效力规定涉及条文 |
|---|---|---|
| 婚姻法 | 第五编婚姻家庭 | 第22、26条 |
| 继承法 | 第六编继承 | 第13、14、15、23条 |
| 民法通则 | 第一编总则（法人、民事法律行为、代理、时效）＋分则散入 | 第1—5条一般规则承载 |
| 收养法 | 第五编婚姻家庭第五章收养 | 第1—5条一般规则承载 |
| 担保法 | 物权编担保物权＋合同编保证合同（流押流质第7条、保证期间第27条） | 第7、27条 |
| 合同法 | 第三编合同 | 第8、9、10、11、20、25条 |
| 物权法 | 第二编物权（含所有权、用益物权、担保物权） | 第7条 |
| 侵权责任法 | 第七编侵权责任 | 第16、17、18、19、24条 |
| 民法总则 | 第一编总则 | 第6条（施行前英烈人格利益） |

## 一、总决策树（先定时间，再定新旧，最后校例外）

```
第0步 定位「法律事实」发生／持续的时点（以引起纠纷的法律事实为准，非起诉日、非合同订立日一刀切）
      │
      ├─ 全部发生在 2021-01-01 之后 ............................ → 直接适用《民法典》（时间效力规定第1条第1款）
      │
      ├─ 全部发生在 2021-01-01 之前（旧事实） → 进入第1步
      │
      └─ 跨越 2021-01-01（持续性法律事实，如继续性合同、持续侵权、
          行为在前结果在后）→ 原则适用《民法典》（第1条第3款），
          但合同履行争议按「施行前／施行后分段」（第20条）；
          侵权按「结果出现在施行后即适用民法典」（第24条）

第1步 旧事实：当时的法律、司法解释有无规定？
      │
      ├─ 有规定 → 原则适用旧法（第2条本文）
      │            │
      │            └─【有利溯及例外】适用民法典更有利于
      │               ①保护民事主体合法权益 ②维护社会经济秩序
      │               ③弘扬社会主义核心价值观 → 适用民法典（第2条但书）
      │
      ├─ 无规定（空白） → 民法典有规定的可适用民法典（第3条），
      │                   但「明显减损权益／增加法定义务／背离合理预期」者除外
      │
      └─ 仅有原则性规定 → 仍适用旧法裁判，但可依民法典具体规定进行裁判说理（第4条）

第2步 核对第三节的「逐条强制溯及清单」（第6—19条）：
      命中者，不问第2条的三项「更有利于」测试，径行适用民法典相应条文（多为「新增规定溯及」）

第3步 核对第四节的「衔接适用清单」（第20—27条）：
      跨施行期的合同、租赁、遗嘱、离婚、保证等，按各条的时点切分规则适用

第4步 再审过滤：民法典施行前已终审、后经再审的案件 → 一律不适用民法典（第5条）
      公司法／海商法／生态环境法典各自另有对应再审规则（见第五节对照）
```

溯及类型三分法（贯穿全篇）：
- 有利溯及（真正溯及／从旧兼有利）：第2条但书、第8条。旧法有规定仍改用民法典，因结果更有利于当事人或秩序。
- 新增规定溯及：第3条＋第6—19条。旧法本无规定，民法典新设规则，就既往事实直接适用；空白溯及以「不背离合理预期」为限。
- 衔接性溯及：第20—27条。法律事实横跨施行日，按行为、结果、期限届满、催告等具体时点分段确定新旧法。

## 二、民法典时间效力规定逐条判断句（第1—5条：一般规定）

以「若…则…」可执行判断句转写。凡「旧法某法某条」处，指第一节九部法律之一。

- 第1条｜时间基准
  - 若法律事实全部发生于2021-01-01之后 → 适用《民法典》。
  - 若法律事实全部发生于2021-01-01之前 → 适用当时的法律、司法解释（即九部旧法及其配套解释），但法律、司法解释另有规定者除外。
  - 若旧事实持续至2021-01-01之后 → 适用《民法典》，但法律、司法解释另有规定者除外。
- 第2条｜有利溯及（从旧兼有利）
  - 若旧事实＋旧法有规定 → 原则适用旧法；但若适用《民法典》更有利于①保护民事主体合法权益②维护社会经济秩序③弘扬社会主义核心价值观 → 改适用《民法典》。
- 第3条｜新增规定溯及（空白溯及）
  - 若旧事实＋旧法无规定＋民法典有规定 → 可适用《民法典》；但若「明显减损当事人合法权益／增加当事人法定义务／背离当事人合理预期」 → 不得溯及适用。
- 第4条｜原则性规定的说理援引
  - 若旧事实＋旧法仅有原则性规定＋民法典有具体规定 → 裁判依据仍是旧法，但可在裁判说理中援引《民法典》具体规定。
- 第5条｜再审排除
  - 若案件在民法典施行前已终审，当事人申请再审或按审判监督程序决定再审 → 不适用《民法典》。

## 五、其他法域的时间效力规则与差异

### 5.1 公司法时间效力规定（法释〔2024〕7号，2024-07-01施行，`T1_012`）

骨架与民法典一致（第1条确立「新事实用新法、旧事实原则用旧法＋有利溯及、持续性事实用新法、已终审再审不适用旧法」），但采用「列举式有利溯及＋无效转有效＋跨期履行」三档，且**未采用「空白溯及一般条款」**，而以逐项清单控制溯及范围。关键判断句：

- 第1条：旧股东会决议可撤销（召集程序不当，1年内诉请撤销，适用第26条第2款）、决议不成立对善意相对人关系（第28条第2款）、债权出资（第48条第1款）、对外转让股权（第84条第2款）、违法分配利润／减资赔偿（第211、226条）、利润分配时限（第212条）、减资出资额争议（第224条第3款）→ 有利溯及适用公司法。
- 第2条：旧认定无效、公司法认定有效的三类（公司对所投资企业债务连带承诺第14条第2款、资本公积金弥补亏损决议第214条、持股90%以上简易合并第219条）→ 有利溯及。
- 第3条：跨施行期履行合同的三类（代持上市公司股票第140条第2款、上市公司控股子公司取得母公司股份第141条、财务资助第163条）→ 分段＋衔接溯及。
- 第4条：旧法无规定而公司法新设（未届出资期限股权转让的出资责任第88条第1款、控股股东滥权强制收购第89条第3、4款、异议股东回购第161条、不担任董事的控股股东／实际控制人责任第180条、指示董监高从事损害行为第192条、不背离合理预期的其他情形）→ 空白溯及，但仍受「合理预期」限制。
- 第5条：旧法仅有原则性规定而公司法具体化 → 章程限制股份转让（第157条）、监事／董监高禁止行为赔偿责任（第181—184条）、关联交易认定（第182条、第265条第4项）→ 溯及适用。
- 第6条：应清算事实发生于施行前 → 原则适用旧法；但至施行日未满15日的，适用第232条，清算义务期限自施行日重新起算（衔接保护）。
- 第7条：施行前已终审、后申请再审或按审判监督再审 → 适用当时的法律、司法解释（与民法典第5条「再审不适用新法」方向一致，此处明确「用旧法」）。

### 5.2 海商法时间效力规定（法释〔2026〕8号，2026-05-01施行，`T4_085`）

针对2025-10-28修订的海商法。结构最接近民法典：第1条一般规则＋第2条空白溯及（附「三不得」限制）＋第3条原则性规定说理＋第4条跨期履行分段。特色溯及项：
- 第5条：施行前约定「船舶抵押权不与担保债权一并转让」→ 适用海商法第18条（新增溯及）。
- 第6条：施行前出具的电子运输记录纠纷 → 适用第4章第5节电子运输记录规定（新设制度溯及）。
- 第7条：施行前订立的预约保险合同，施行后被保险人申报／保险人主张违约责任 → 适用第259条；施行前违反如实告知或保证条款、施行后保险人解除合同 → 适用第248、261条。
- 第8条：施行日时效期间尚未届满的，时效中止适用「中止原因消除之日」的法律、司法解释，时效中断适用「中断事由发生时」的法律、司法解释（时效衔接的细分规则，民法典、公司法均无此条，属海商特有）。
- 第9条：施行前已终审、后申请再审 → 适用当时的法律、司法解释。
- 第10条：施行后尚未审结的一审、二审案件适用本规定。

### 5.3 生态环境法典时间效力规定（法释〔2026〕15号，2026-08-15施行，`T4_916`）

首批配套生态环境法典的解释，**同时处理民事与行政案件**（跨法域，独此一家）。判断句：
- 第1条：一般规则（新事实用新法；旧事实原则用旧法＋另有规定除外）。注意**未设「持续性事实适用新法」的明文款**，改由第4条侵权条款承载。
- 第2条：旧法仅有原则性规定而法典有具体规定 → 仍适用旧法＋依法典具体规定说理（对应民法典第4条）。
- 第3条：跨施行期合同分段（对应民法典第20条）。
- 第4条：①施行前侵权行为持续至施行后 → 适用法典；②行为在前、结果在后，且属土壤及地下水污染责任人无法认定时土地使用权人未履责（第1066条第1款）、生态环境技术服务机构违规担责（第1067条）、海洋倾倒／固废委托未尽核实监督义务（第1068条第1款）、境外固废／放射性废物输入（第1068条第2款）等 → 适用法典（对应民法典第24条的细化）。
- 第5条：五年诉讼时效的溯及（详见第六节冲突）：施行日三年时效（民法典第188条）尚未届满的，可主张法典第1054条第2款五年时效；施行前三年时效已届满的，不支持。
- 第6条：施行后审理生态环境保护民事公益诉讼 → 适用法典第1081条提供证明的规定。
- 第7条：施行后对具有重大风险的污染破坏行为采取禁止令保全 → 适用法典第1079条。
- 第8条：施行前违法行为有连续或继续状态、施行后终了 → 生态环境行政案件适用法典。
- 第9条：施行后行政案件 → 依法典第1057条确定适用的生态环境法律、法规、规章。
- 第10条：派出机构以自己名义执法的被告确定（施行前的行为、施行后起诉的受理与施行后的被告确定分别规定）。
- 第11条：责任相当原则＋从轻减轻（施行前行为施行后处罚，有主动消除减轻后果、生态修复、及时缴纳赔偿金等，可适用法典第1056条第2款从轻减轻）。
- 第12条：施行前已终审、后申请再审 → 不适用法典。
- 第13条：施行与「尚未审结一审二审适用本规定」的过渡。

## 六、跨法典竞合与新旧解释冲突处理

### 6.1 建工解释（一）与解释（二）的适用顺位

两件现行有效、需同时使用：
- 解释（一）：法释〔2020〕25号，2021-01-01施行，共45条（`T2_006_审理建设工程施工合同纠纷案件.md`）。
- 解释（二）：法释〔2026〕12号，2026-06-30施行，共23条（`T2_903_审理建设工程施工合同纠纷案件.md`，2026补抓件）。

顺位规则（解释二第23条原文）：
1. 解释二自2026-06-30施行；**施行后新受理的一审**建工合同纠纷案件适用解释二。
2. **施行后，最高人民法院以前发布的司法解释与解释二不一致的，以解释二为准**。故解释二与解释（一）就同一事项冲突时，解释二优先。
3. 二者不冲突的部分并行适用——解释二并未整体取代解释（一）（旧法释〔2018〕20号已废止；解释二与2020修正后的解释（一）配套适用）。

典型冲突点与应采立场：
- 实际施工人突破合同相对性直诉发包人：解释（一）第43条允许实际施工人以发包人为被告、发包人在欠付范围内担责（追加转包／违法分包人为第三人）；解释二第4—7条改以合同相对性＋代位权路径为主（借用资质／转包情形下第7条指引以民法典第535条代位权行使）。**2026-06-30后新受理一审案件**应优先按解释二路径处理；解释二施行前已受理或未审结案件，直诉发包人仍可援引解释（一）第43条（需回查具体案件受理时点，见 `T2_006` 第43条、`T2_903` 第4—7条）。
- 违法招标认定无效：解释二第1条明确「订立时属必须招标、起诉时不再属必须招标的，不应仅以未招标认定无效」，与解释（一）第1条合同无效情形不一致 → 以解释二为准。
- 农民工工资：解释二第8条单独规定请求建设单位／总包／分包的顺位（先行垫付），解释（一）无 → 直接适用解释二。
- 优先受偿权：解释（一）第35—42条 + 解释二第17—22条（折价协议行使第807条、债权受让人优先受偿、工期顺延后起算等）→ 细化事项以解释二为准，未冲突部分仍适用解释（一）。

### 6.4 一般冲突处理顺位（跨法域通用）

1. 先按各法域时间效力规定确定「新法还是旧法」——民法典 / 公司法 / 海商法 / 生态环境法典 / 著作权法各自独立，不得混用溯及规则。
2. 同一事项有多件司法解释、不同期次并存时，看新件的「不一致以本解释为准」条款（如建工解释二第23条、精神损害解释第6条）；无此条款者，按「特别解释优先于一般解释、新解释优先于旧解释」。
3. 民法典时间效力规定第5条与公司法第7条、海商法第9条、生态环境法典第12条：已终审再审案件一律「用旧法／不用新法」，方向一致。
4. 有利溯及（第2条但书、第8条）为兜底——即使不落入第6—19条清单，仍可用第2条「三项更有利于」测试争取适用民法典。
