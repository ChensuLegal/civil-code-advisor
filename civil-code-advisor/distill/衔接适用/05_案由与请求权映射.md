# 05 案由与请求权映射表

> 案由名称与序号一律取自 2025 年 12 月第三次修正、重新印发的《民事案件案由规定》（法〔2025〕226号修改决定／法〔2025〕227号印发，2026-01-01 施行，语料 T1_905）。体系为纵 12 部分、横四级：12 个第一级部分、59 个第二级、514 个第三级、470 个第四级案由。
> 案由确定标准（印发通知第三部分）：以当事人诉争的**民事法律关系性质**为准，表述为"法律关系性质＋纠纷"；涉及物权变动的，原因行为（债权性合同）归第四部分"合同纠纷"，变动结果（设立、权属、效力、使用、收益）归第三部分"物权纠纷"。侵权优先规则：先适用第十部分"侵权责任纠纷"项下具体案由，无对应再回到人格权、物权等部分。
> 司法解释编号：合同编通则解释T1_002、担保制度解释T1_008、物权编解释（一）T1_007、婚姻家庭编解释（一）T1_003／（二）T1_006、继承编解释（一）T1_009、诉讼时效规定T1_010、商品房消费者权利批复T2_052、房屋租赁解释T2_009、民间借贷规定T2_011、医疗损害责任规定T2_003、人身损害赔偿解释T2_029、涉彩礼纠纷规定T2_033、建筑物区分所有权解释T4_001、农村土地承包解释T4_014、生态环境侵权证据规定T3_004、民诉法解释T3_001、执行异议之诉解释T3_002、变更追加当事人规定T3_059、财产保全规定T3_005。
