# 蒸馏层统一规格（所有子代理必须先读本文件）

## 目标
把《民法典》1260 条与 271 件现行有效民事/商事/程序类司法解释的**全文**蒸馏为可直接用于办案的结构化知识，
供 AI 代理在起草文书、审查合同、应诉答辩时精确援引。**禁止只按目录、章名、篇名概括**——每一条都要落到条号。

## 语料位置（只读，不得修改）
- 民法典逐条 JSONL：`corpus\mfd\articles.jsonl`
  每行 `{"no":条号,"label":"第X条","part":"第一编总则","subpart":"","chapter":"第一章基本规定","section":"","text":"正文","paras":["第1款","第2款"]}`
- 条文分片（给蒸馏子代理阅读用）：`<工作区>/out\mfd_chunks\NN_名称.txt`
  每行 `{"no":条号,"label":"第X条","part":"第一编总则","subpart":"","chapter":"第一章基本规定","section":"","text":"正文","paras":["第1款","第2款"]}`
- 民法典分编全文：`corpus\mfd\民法典_01_第一编总则.md` … `_08_附则.md`
- 司法解释全文：`corpus\ssjf\<文件名>.md`（文件名前缀 T1_/T2_/T3_/T4_）
- 文件与层级清单：`index\corpus_files.tsv`（列 file/tier/topic/fashi/eff_date/chars/tiao/title/flk_url）
- 条文级全量记录（解释的每一条 + 已抽到的民法典引用锚点）：`index\articles_all.jsonl`
- 民法典条文被引倒排：`index\xref_mfd.tsv`
- 时间效力衔接条款：`index\transition.tsv`

## 产出位置
写到 `distill\` 下指定的子目录，UTF-8。文件名按任务书指定，不要自创别的文件。

## 硬约束
1. **必须读全文**：用 Read 工具把负责的语料读完整（大文件分批 offset 读完），不得只读开头或只读索引推断。
2. **只写有依据的内容**：每一条卡片都要有确切条号。不得写"见相关司法解释"这类空指。
3. **区分规范功能**：请求权基础／构成要件／法律效果／定义／推定／拟制／准用与参照／例外／期间／衔接与溯及力／宣示与原则。
4. **不得编造司法解释条文号或原文**；引用解释条文时同时给文件名（如 `担保制度解释第6条`）与条号。
5. 民法典第X条的**款/项**要区分（"第X条第1款第2项"），JSONL 里 paras 数组第 1 项是第 1 款。
6. 语言：简体中文，专业判断式，不用口语比喻，不用"值得注意的是"这类填充语；卡片正文短句为主。
7. 不用 emoji。标点用中文直角引号「」或全角引号，与语料一致即可，不改动引文。
8. 写完后自查：卡片条数必须等于你负责范围的条文数（民法典某编则等于该编条数），并在返回消息里报告计数。

## 条文卡片格式（要件卡片/）
每条一节，紧凑但完整：

```markdown
### 第509条｜合同全面履行与绿色履行
- 定位：第3编合同｜第1分编通则｜第7章合同的效力｜（无节）
- 功能：行为规范+裁判依据（双规范）
- 规则：当事人应按约定全面履行义务；应履行通知、协助、保密等附随义务；应避免浪费资源、污染环境和破坏生态。
- 要件：①有效合同 ②约定内容明确 ③履行行为与约定不符
- 效果：构成违约，触发第577条继续履行/补救措施/赔偿损失
- 配套解释：合同编通则解释（T1_002）第3条（附随义务具体化）、第24条（违约方起诉解除）
- 举证：主张附随义务方证明义务存在及违反；履行方证明已按约履行
- 易错：把"绿色原则"条款当成可直接请求停止污染的请求权基础（应走侵权编或人格权禁令）
- 援引示例：「依据《民法典》第五百零九条第二款，被告负有协助办理过户的附随义务」
```

字段可精简（无内容就省略该行），但「功能」「规则」「配套解释」三行必须有。
「配套解释」行必须写具体文件与条号；确实没有配套规定的，写 `配套解释：无直接对应司法解释`。

## 请求权基础文件格式
```markdown
## 争点：<一句话争点表述，如"合同是否因违反强制性规定而无效">
- 请求权基础/抗辩规范：民法典第X条（+ 第X条第X款）
- 构成要件树：
  1. 要件A —— 证明责任：原告；核心证据：…
  2. 要件B —— 反驳路径：…
- 法律效果：…
- 关键司法解释：文件名+条号（写明该条解决什么）
- 常见抗辩与反击：…
- 期间与时效：…
- 案由对应：民事案件案由规定 …
- 检索口令：给 AI 的检索关键词组合
```
