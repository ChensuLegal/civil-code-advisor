# 主干配套司法解释速查卡·B组（逐条）
> 规格：见 `distill/_SPEC.md`。卡片格式：`解释第N条｜规范对象：民法典第X条（含款/项）｜一句话规则（≤40字）｜类型：细化/新增规则/衔接与溯及/程序｜风险提示（确有需要才写）`
> 民法典条号系原文未点明而由本卡判定的，加 `(推定)`；确无民法典条文可挂的程序性/新设规则，规范对象记「无直接挂载」。
> 语料源文件（只读）：T1_002／T1_003／T1_006／T1_009／T1_005／T1_010（`corpus/ssjf/`）。
> **编号体例总结论**：六件正文条文一律以中文数字「第X条」连续编号，不存在以「一、二、三」充当条号的情形；T1_002（一至九）、T1_003（一至六）、T1_009（一至五）中出现的「一、二、三」仅为章级标签（如「一、一般规定」），援引时条文号仍以「第X条」为准。T1_006、T1_005、T1_010 无分章，条文直排。
