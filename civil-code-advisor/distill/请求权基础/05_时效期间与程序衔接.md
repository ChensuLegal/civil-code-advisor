## 争点：普通诉讼时效期间的起算（"知道或应当知道＋义务人"双要件）
- 请求权基础/抗辩规范：民法典第188条第1款（3年；自权利人知道或应当知道权利受到损害以及义务人之日起计算）
- 构成要件树：
  1. 权利受到损害 —— 客观面，主张时效完成方先证明损害发生时点
  2. 知道或应当知道损害 —— 主观面，"应当知道"按理性人＋注意义务推定
  3. 知道或应当知道义务人 —— 欠缺该要件则不起算（如错汇款项不知收款人身份）
  4. 反驳路径：债务人以"合同到期即应知"抗辩 → 对照未约定履行期限合同规则（T1_010第4条：可确定履行期限的自期限届满起算；不能确定的自宽限期届满起算，但债务人首次被主张时明确拒绝的自拒绝之日起算）
- 法律效果：期间届满义务人取得抗辩权（第192条）
- 关键司法解释：诉讼时效规定（T1_010）第4条（未定履行期限合同）；总则编解释（T1_004）第36条（无/限制行为能力人之权利受损，自其法定代理人知道或应当知道损害及义务人之日起算）
- 常见抗辩与反击：以"发票开具日"主张起算 → 应回到权利可行使且知道义务人的双要件；以刑事报案中断另行主张（见中断节点）
- 期间与时效：3年；法律另有特别期间（如第594条国际货物买卖4年）优先
- 案由对应：按基础法律关系确定案由，时效为抗辩不单独成案由
- 检索口令：诉讼时效起算＋188条＋知道义务人＋宽限期＋未约定履行期限＋4条

## 争点：分期履行、对法定代理人及未成年人性侵等特殊时效起算
- 请求权基础/抗辩规范：民法典第189条（同一债务分期履行：自最后一期履行期限届满之日起算）、第190条（对法定代理人的请求权：自法定代理终止之日起算）、第191条（未成年人性侵损害赔偿：自年满18周岁之日起算）
- 构成要件树：
  1. "同一债务分期履行"识别：本金分期（适用第189条）与独立定期给付（如租金逐期起算）区分
  2. 第190条限"对其法定代理人"的请求权
  3. 第191条不问何时知悉加害人，一律自18周岁起算3年（特别起算规则优先于第188条）
  4. 补充：原法定代理人侵害且在恢复行为能力或新代理人确定后方知悉 → 适用第188条第2款＋T1_004第36条（T1_004第37条）
- 法律效果：确定时效起点后适用中止中断规则（20年期间除外，见最长保护期节点）
- 关键司法解释：总则编解释（T1_004）第36、37条（法定代理人起算的两层规则）；诉讼时效规定（T1_010）第5条第2款（合同被撤销后返还财产、赔偿损失请求权自撤销之日起算）、第6条（不当得利）、第7条（无因管理）
- 常见抗辩与反击：义务人以"各期租金分别起算"抗辩总额请求 → 区分同一债务分期与定期给付之债；以"已满18岁多年"抗辩性侵赔偿 → 核查是否存在中止事由与障碍
- 期间与时效：均3年，起算点分别法定
- 案由对应：基础关系案由；性侵害赔偿按人格权纠纷/侵权责任纠纷
- 检索口令：189条最后一期起算＋分期履行＋190条法定代理终止＋191条未成年人年满十八周岁＋撤销合同之日起算

## 争点：诉讼时效中止（最后六个月＋法定障碍）
- 请求权基础/抗辩规范：民法典第194条（最后六个月内因不可抗力；无/限制行为能力人无法定代理人或法定代理人死亡、丧失能力、丧失代理权；继承开始后未确定继承人或遗产管理人；权利人被义务人或他人控制；其他障碍→中止；自中止原因消除之日起满六个月届满）
- 构成要件树：
  1. 障碍发生于时效期间最后六个月内（或在前但延续至最后六个月）—— 权利人举证
  2. 障碍属五项法定情形且导致不能行使请求权（因果关系）
  3. "继承开始后未确定继承人或者遗产管理人"与第1145-1146条衔接：申请指定遗产管理人即消除障碍
- 法律效果：中止原因消除之日起满6个月期间方届满（残余期间一律补足6个月）
- 关键司法解释：总则编解释（T1_004）第35条（第188条第1款3年可中止中断、不适用延长；第2款20年不适用中止中断）
- 常见抗辩与反击：义务人以"障碍仅造成不便"抗辩 → 审查"不能行使请求权"的客观性；不可抗力主张需证明与行使障碍的因果
- 期间与时效：20年最长保护期间不发生中止（第188条第2款但书＋T1_004第35条）
- 案由对应：抗辩规范，不单独成案由
- 检索口令：时效中止＋最后六个月＋遗产管理人未确定＋权利人被控制＋满六个月届满

## 争点：诉讼时效中断（提出请求、同意履行、起诉及同等效力事由）
- 请求权基础/抗辩规范：民法典第195条（四情形；从中断、有关程序终结时起重新计算）
- 构成要件树：
  1. 权利人向义务人提出履行请求 —— T1_010第8条四情形：送交文书（签名盖章按指印或其他到达证明）；信件或数据电文到达或应当到达；金融机构依约扣收本息；公告催收（国家级或省级有影响力媒体，限于对方下落不明）
  2. 签收主体扩张：法人由法定代表人、主要负责人、收发部门或被授权主体签收；自然人本人、同住完全行为能力亲属或被授权主体（T1_010第8条第2款）
  3. 义务人同意履行 —— 分期履行、部分履行、提供担保、请求延期、制定清偿计划（T1_010第14条）
  4. 起诉或申请仲裁 —— 提交起诉状或口头起诉之日即中断（T1_010第10条）；与起诉同等效力的八事项（支付令、破产申请与债权申报、宣告失踪死亡、诉前保全与诉前临时禁令、申请执行、追加当事人或被通知参加诉讼、诉讼中主张抵销等——T1_010第11条）；向人民调解委员会等社会组织请求保护（第12条）；向公安检察院法院报案控告（第13条，不立案撤案不起诉之日起重新计算；刑案审理阶段自刑事裁判生效日重新计算）
  5. 涉他扩张：部分主张及于剩余债权（第9条）；连带债权人/债务人一人中断及于他人（第15条）；代位权诉讼对两个债权均中断（第16条）；债权转让自通知到达债务人中断、债务承担自意思表示到达债权人中断（第17条）；向义务人的代理人、财产代管人、遗产管理人提出请求亦中断（T1_004第38条第2款）
- 法律效果：时效重新起算；新期间内再现第195条事由可再次中断（T1_004第38条第1款）
- 关键司法解释：T1_010第8-17条；T1_004第38条
- 常见抗辩与反击：义务人主张"微信催收非书面请求"→ 数据电文到达即可（T1_010第8条第2项）；对账单仅有签收无主张内容 → 证明该文书含主张权利内容
- 期间与时效：中断后重新起算3年；注意第2款"有关程序终结时起"（诉讼、破产、执行程序终结为起算点）
- 案由对应：抗辩规范
- 检索口令：时效中断＋催收＋到达主义＋诉前禁令中断＋报案中断＋连带债务人中断＋债权转让通知

## 争点：时效届满的效果——抗辩权发生、放弃抗辩与法院不得主动适用
- 请求权基础/抗辩规范：民法典第192条（届满可抗辩；同意履行后不得再抗辩、自愿履行不得请求返还）、第193条（法院不得主动适用）
- 构成要件树：
  1. 抗辩须当事人提出：法院不应释明（T1_010第2条）
  2. 提出阶段：一审未提、二审提出不予支持，但基于新证据能证明已过时效除外；届满后以时效为由申请再审或提再审抗辩不予支持（T1_010第3条）
  3. 放弃抗辩的形式：作出同意履行意思表示或自愿履行（第192条第2款）；达成新还款协议即放弃（T1_010第19条第2款）；催款通知单签字盖章且可认定同意履行（第19条第3款；另参法释〔1999〕7号批复 T1_015、T1_011关于无还款日期欠条自收到条次日明确拒偿之日起算）
  4. 已受领给付不得以不知时效为由请求返还（自然债务）
- 法律效果：胜诉权消灭、实体权利保留
- 关键司法解释：T1_010第2、3、19条；T1_011；T1_015
- 常见抗辩与反击：债务人在逾期对账函上仅盖章未表态 → 审查函件内容是否含"同意履行"意思，单纯签收不构成放弃；金融机构主张"扣息即放弃抗辩"→ 须为对到期债务的主动承认
- 期间与时效：放弃抗辩后重新起算3年
- 案由对应：抗辩规范；离婚后财产、民间借贷等案件中高频
- 检索口令：192条＋时效抗辩＋不得释明＋二审新证据＋催款通知单盖章＋重新确认债务＋1999年7号批复

## 争点：不适用诉讼时效的请求权清单
- 请求权基础/抗辩规范：民法典第196条（停止侵害、排除妨碍、消除危险；不动产物权和登记的动产物权的权利人请求返还财产；请求支付抚养费、赡养费或扶养费；其他依法不适用者）、第995条第2款（人格权防御性请求权）、第1079条（离婚请求——身份关系解除不受时效）
- 构成要件树：
  1. 债权请求权原则上适用时效，但T1_010第1条排除：支付存款本金及利息请求权；兑付国债、金融债券及向不特定对象发行的企业债券本息请求权；基于投资关系产生的缴付出资请求权；其他依法不适用者
  2. 第196条第2项限"登记的"动产物权返还（占有改定未登记者不受保护层级降低）
  3. 抚养费赡养费扶养费：本金给付请求不适用（第196条第3项），已到期未付各期给付的财产请求权性质有争议，起诉时点从宽
- 法律效果：义务人时效抗辩不成立
- 关键司法解释：T1_010第1条；婚姻家庭编解释（一）（T1_003）第84条反面解释（1092条再分割适用3年，与之对照）
- 常见抗辩与反击：储户追索存款遇"银行以久未主张抗辩"→ 存款本息请求权不适用时效；股东出资请求不受时效（公司诉缴或管理人追缴同）
- 期间与时效：本节点即清单
- 案由对应：储蓄存款合同纠纷、股东出资纠纷、抚养费纠纷等
- 检索口令：不适用诉讼时效＋存款本息＋缴付出资＋登记的动产返还＋抚养费196条＋995条第2款

## 争点：诉讼时效的法定性——约定无效、预先放弃无效与仲裁时效衔接
- 请求权基础/抗辩规范：民法典第197条（期间、计算方法、中止中断事由法定，约定无效；对时效利益的预先放弃无效）、第198条（法律对仲裁时效有规定依其规定，无规定适用诉讼时效）
- 构成要件树：
  1. 合同"对账后X日不异议视为放弃权利""延长时效至10年"等条款 → 无效
  2. 届满后放弃抗辩允许（第192条第2款）；届满前放弃一律无效
  3. 仲裁时效：劳动仲裁1年特别规定优先（劳动争议调解仲裁法），民事仲裁适用3年
  4. 特别法定期间：第594条国际货物买卖合同与技术进出口合同4年
- 法律效果：约定不产生变更期间的效力，仍按法定期间计算
- 关键司法解释：诉讼时效规定（T1_010）第20条（施行后未终审案件适用新规）、第21条（旧解释抵触以新规为准）；时间效力规定（T1_001）衔接旧法2年期间案件
- 常见抗辩与反击：以"合同约定20年付清"规避时效 → 履行期限约定本身有效（影响起算），但缩短延长时效的部分无效——区分履行期限与时效期间
- 期间与时效：3年／4年／特别法
- 案由对应：抗辩规范
- 检索口令：时效法定＋197条＋预先放弃无效＋仲裁时效＋198条＋594条四年

## 争点：20年最长保护期间的适用与延长
- 请求权基础/抗辩规范：民法典第188条第2款后段（自权利受到损害之日起超过20年的不予保护；特殊情况可根据权利人申请决定延长）
- 构成要件树：
  1. 起算点＝权利受到损害之日（客观标准，不问知悉）
  2. 不适用中止、中断（T1_004第35条第2句）
  3. "延长"须权利人申请＋特殊情况（如人身损害多年后发现病因、历史遗留权属）
- 法律效果：超过20年法院不予保护；3年主期间可并行审查（20年内届满但超过3年的以时效抗辩审查为主）
- 关键司法解释：总则编解释（T1_004）第35条
- 常见抗辩与反击：被告仅主张3年时效经过 → 法院不主动审查20年（第193条）；权利人请求延长须说明客观障碍
- 期间与时效：20年不变期间（可申请延长）
- 案由对应：抗辩规范
- 检索口令：20年最长保护期＋权利受到损害之日＋不适用中止中断＋申请延长＋188条第2款

## 争点：除斥期间的一般规则及其与诉讼时效的区分
- 请求权基础/抗辩规范：民法典第199条（法律规定或当事人约定的撤销权、解除权等权利的存续期间，自权利人知道或应当知道权利产生之日起计算，不适用中止、中断、延长；届满权利消灭）、第152条（意思表示撤销权消灭四情形＋5年最长）
- 构成要件树：
  1. 对象：形成权（撤销权、解除权、受遗赠表示权等），非请求权
  2. 起算：知道或应当知道权利产生之日；撤销权自知道撤销事由起1年、重大误解90日、胁迫自胁迫终止起1年、行为发生之日起5年（第152条）
  3. 效果区别：时效届满→抗辩权发生（诉权保留）；除斥届满→实体权利消灭（法院应依职权审查）
  4. 对撤销合同请求权提出诉讼时效抗辩的不予支持（T1_010第5条第1款）
- 法律效果：权利消灭；已行使形成权的效果不可逆
- 关键司法解释：T1_010第5条
- 常见抗辩与反击：相对人以"撤销权过时效"抗辩 → 定性错误，除斥期间不适用中断，但需核"知道撤销事由"时点；欺诈撤销中5年客观期间为绝对上限
- 期间与时效：见第152条各档
- 案由对应：可撤销合同、重大误解等纠纷中审查
- 检索口令：除斥期间＋199条＋形成权＋撤销权消灭＋90日一年五年＋依职权审查

## 争点：债权人撤销权、合同解除权与婚姻撤销权的除斥期间
- 请求权基础/抗辩规范：民法典第541条（债权人撤销权：知道或应当知道撤销事由1年；行为发生之日起5年）、第564条（解除权：法定或约定期限，无期限的自解除权人知道或应当知道解除事由之日起1年不行使或经催告后合理期限内不行使消灭；行为发生5年上限参照第199条）、第1052条（胁迫结婚：自胁迫行为终止之日起1年）、第1053条（隐瞒重大疾病：自知道或应当知道撤销事由之日起1年）
- 构成要件树：
  1. 撤销权诉讼被告为相对人（受益人/受让人），债务人为第三人
  2. 解除权行使除斥期间1年（知道解除事由起），催告后为"合理期限"
  3. 婚姻撤销：受胁迫/被非法限制人身自由的1年期间不适用时效中止中断延长（T1_003第19条第1款），且不适用第152条第2款5年上限（T1_003第19条第2款）
  4. 撤销权诉讼中同时请求返还：合同编通则解释（T1_002）第46条（请求相对人向债务人承担返还财产、折价补偿、履行到期债务）
- 法律效果：期间届满形成权消灭，基础行为确定有效/解除权不得再行使
- 关键司法解释：T1_002第46条（债权人撤销权后果）；婚姻家庭编解释（一）（T1_003）第18、19条（胁迫认定＋期间性质）
- 常见抗辩与反击：以"离婚协议财产条款已履行"抗辩撤销 → 参照T1_006（法释〔2025〕1号）第3条债权人撤销离婚协议财产条款路径；欺诈方以对方"早应知道"抗辩 → 举证应知时点的具体事实
- 期间与时效：1年／5年各档；均除斥期间
- 案由对应：债权人撤销权纠纷、确认合同解除纠纷、撤销婚姻纠纷（18号案由）
- 检索口令：541条＋1年5年＋解除权1年＋催告合理期限＋婚姻撤销1年＋不适用中止中断＋法释2025年1号第3条

## 争点：保证期间的性质、约定不明识别与保证责任消灭
- 请求权基础/抗辩规范：民法典第692条（保证期间系确定保证人承担保证责任的期间，不发生中止、中断和延长；无约定或约定不明为主债务履行期届满之日起6个月）、第693条（一般保证：债权人未在保证期间对债务人提起诉讼或申请仲裁→保证人不再担责；连带保证：未在保证期间请求保证人承担→同）
- 构成要件树：
  1. "承担至本息还清时为止"类条款＝约定不明→6个月（担保制度解释第32条）
  2. 一般保证中在保证期间起诉后又撤诉且届满前未再起诉→保证人免责；连带保证中撤回起诉但起诉状副本已送达保证人→视为已行使权利（担保制度解释第31条）
  3. 最高额保证起算按约定，无约定按债权确定日/最后到期日（第30条）
  4. 共同保证：向部分保证人行权不及于其他（第29条第1款）
  5. 法院应依职权查明保证期间是否届满（第34条第1款）；届满后保证人在催款通知上签章原则上不复活（第34条第2款，新保证合同除外）
  6. 主债务时效届满→保证人援用主债务人抗辩（T1_010第18条第1款）；未主张而承担后追偿受限（第18条第2款）
- 法律效果：保证期间届满保证责任实体消灭；保证债务诉讼时效另行起算（694条，一般保证自债权人知悉债务人财产强制执行仍不能履行时起算；担保制度解释第28条对"先诉抗辩权例外情形下自债权人知道或应当知道之日起算"）
- 关键司法解释：担保制度解释（法释〔2020〕28号，T1_008）第27条（公证债权文书执行与保证期间）、第28条（保证债务时效起算）、第29-34条；诉讼时效规定（T1_010）第18条
- 常见抗辩与反击：债权人对一般保证人直接起诉 → 先诉抗辩权（687条）＋期间届满双重抗辩；以"对账单盖章"主张保证人重新担责 → 核T1_008第34条第2款新保证合意要件
- 期间与时效：保证期间6个月/约定期间（除斥性质）；保证债务时效3年（694条）
- 案由对应：保证合同纠纷、金融借款合同纠纷
- 检索口令：保证期间＋692条＋本息还清为止约定不明＋6个月＋撤回起诉＋保证债务诉讼时效＋担保制度解释34条

## 争点：优先购买权行使期间与共有物分割请求的"无期间"特性
- 请求权基础/抗辩规范：民法典第726条第2款（承租人：出租人履行出卖通知义务后15日内未表示购买视为放弃优先购买权）、第305-306条（按份共有人转让份额：其他共有人同等条件优先购买；转让人应将转让条件及时通知其他共有人，合理期限内未主张视为放弃——306条第2款"合理期限"依转让协议、交易习惯等确定）、第303条（共有物分割：约定不得分割的有重大理由仍可请求；无约定按份共有人可随时请求）
- 构成要件树：
  1. 通知到达＋15日（承租人）—— 出租人举证通知内容含"同等条件"
  2. 未通知即出卖 → 承租人可请求损害赔偿但不影响买卖合同效力（第728条）
  3. 共有份额优先购买：书面通知载明行权期间，未通知的自其他共有人知道最终转让条件之日起算（参照物权编解释与租赁解释规则体系）
  4. 分割请求权：非形成权行使期间限制问题——按份共有人随时可诉；约定禁止分割期间内"重大理由"例外（第303条）
- 法律效果：期间届满形成权消灭；分割请求不受除斥期间但涉共有物占用费返还适用3年时效
- 关键司法解释：房屋租赁解释（T2_009）第15条（出租人与抵押权人折价变卖租赁房屋偿债应合理期限内通知承租人，承租人可主张优先购买）
- 常见抗辩与反击：买受人以"已过户"抗辩承租人优先购买 → 登记过户不阻却损害赔偿（728条），恶意串通除外（154条）；共有人以"约定永不分割"抗辩 → 重大理由审查（急需医疗费、共有物面临灭失）
- 期间与时效：15日／合理期限（均除斥性质）
- 案由对应：承租人优先购买权纠纷、共有物分割纠纷（物权纠纷部分）
- 检索口令：优先购买权＋15日＋同等条件＋306条合理期限＋303条重大理由＋随时请求分割

## 争点：民事期间的计算（起算、届满与节假日顺延）
- 请求权基础/抗辩规范：民法典第200条（按公历年月日小时）、第201条（按年月日计算：开始当日不计入；按小时计算自法定或约定时间起）、第202条（到期月对应日；无对应日月末日）、第203条（最后一日为法定休假日→休假日结束的次日为最后一日；截止24时，有业务时间的停止业务活动时截止）、第204条（约定或法定计算方法优先）
- 构成要件树：
  1. 适用对象：时效、除斥期间、撤销权60日、上诉期等"期间"通用（法律另有规定除外）
  2. 离婚冷静期等行政程序期间参照民法典计算惯例，另按《婚姻登记工作规范》口径核对
- 法律效果：期间届满日决定权利行使是否逾期
- 关键司法解释：民诉法解释第318条（口头表示上诉须在法定上诉期内递交上诉状，否则视为未上诉；递交上诉状未按期交纳上诉费按自动撤回上诉处理）；简易程序规定（T3_072）第31条（定期宣判之日为送达之日，上诉期自次日起算；宣判日无正当理由未到庭不影响上诉期计算）
- 常见抗辩与反击：以末日为节假日争顺延 → 仅法定休假日顺延，周末与法定节假日均计"法定休假日"（实践口径），调休上班日争议须个案说明；电子送达生效时点与"当日不计入"叠加计算
- 期间与时效：本节点即规则
- 案由对应：程序争点，随主案由
- 检索口令：期间计算＋开始当日不计入＋对应日＋休假日顺延＋24时截止＋上诉期次日起算

## 争点：送达（公告送达、特殊主体送达与送达日期确定）
- 请求权基础/抗辩规范：程序规范（民事诉讼法送达制度＋民诉法解释）
- 构成要件树：
  1. 公告送达条件：受送达人下落不明或用其他方式无法送达——穷尽手段前置
  2. 公告方式与生效：公告栏、住所地张贴、报纸或信息网络媒体刊登，以最后张贴或刊登日为发出日，公告期满视为送达（民诉法解释第138条）；公告内容要求（第139条：送达裁判文书须说明裁判主要内容、上诉权利、期限与法院）
  3. 禁止：简易程序案件不适用公告送达（第140条）
  4. 离婚案件一方下落不明：只诉离婚不申请宣告失踪的应受理并公告送达（第217条）
- 法律效果：送达生效决定上诉期、再审申请期、缺席判决合法性
- 关键司法解释：民诉法解释第138、139、140、217条；法院专递邮寄送达规定（法释〔2004〕13号，T3_027，专递送达生效规则）；在线诉讼规则（法释〔2021〕12号，T3_010，电子送达确认与生效时点）
- 常见抗辩与反击：以"未经传票传唤缺席判决"申请再审（对应民诉法解释第389条辩论权剥夺情形）→ 审查送达链条完整性；邮寄送达退回不等于未送达（专递规定按签收与拒收规则认定）
- 期间与时效：公告期届满日＋15日上诉期衔接
- 案由对应：程序争议载体案由
- 检索口令：公告送达＋简易程序不得公告＋上诉权利告知＋专递邮件送达＋电子送达＋下落不明离婚

## 争点：举证责任分配的一般规则与证明标准
- 请求权基础/抗辩规范：《民事诉讼法》"当事人对自己提出的主张有责任提供证据"原则＋民诉法解释第90条（举证责任）、第91条（分配原则：主张法律关系存在→对产生该法律关系的基本事实举证；主张变更、消灭或权利受妨害→对相应基本事实举证）
- 构成要件树：
  1. 行为意义上的举证责任（提供证据）与结果意义上的举证责任（真伪不明时败诉风险）区分
  2. 一般证明标准：高度可能性（民诉法解释第108条第1款）；反驳证据使待证事实真伪不明即完成反驳（第108条第2款）
  3. 提高标准：欺诈、胁迫、恶意串通事实及口头遗嘱、赠与事实——排除合理怀疑（第109条）
  4. 免证事实：众所周知、自然规律定理、推定事实、生效裁判确认的基本事实、有效公证文书证明的事实、自认等（民诉法解释第93条；证据规定法释〔2019〕19号第10条同旨）
  5. 证明妨碍：控制证据无正当理由拒不提交，主张该证据内容不利于控制人的可认定主张成立（证据规定第95条）
  6. 法院调查收集：因客观原因不能自行收集的申请法院收集（民诉法解释第94条；T2_028第5条在保护令案件中的衔接）
- 法律效果：真伪不明时负担结果责任方败诉
- 关键司法解释：民诉法解释第90、91、93、94、108、109条；证据规定（T3_062）第10条、第95条
- 常见抗辩与反击：对方以"你未举证即应败诉"抗辩 → 用第91条重新定位要件事实归属（如合同有效要件在原告，消灭事由在被告）
- 期间与时效：举证期限内申请延期举证、调查取证
- 案由对应：全案由通用
- 检索口令：举证责任分配＋91条＋高度可能性＋排除合理怀疑＋证明妨碍95条＋免证事实

  1. 先固定基础事实（损害＋场所＋物件／诊疗／排放行为）
  2. 推定转移：被告举证无过错／无因果关系／法定免责事由
  3. 医疗案件患方仍就诊疗关系与损害举证，过错及因果部分推定（对照T2_003医疗损害责任规定相关条文）
  4. 环境案件原告仍须证明：排放行为、损害、初步关联（生态环境侵权证据规定（T3_004）第1条至第6条对举证内容细化；因果关系推定的间接证据链）
- 法律效果：被告不能反证即承担不利认定
- 关键司法解释：生态环境侵权民事诉讼证据规定（T3_004）；医疗损害责任规定（T2_003）
- 常见抗辩与反击：加害人以"第三方原因"抗辩环境责任 → 1233条第三方追偿路径而非免责；医疗中以"病历客观无法提供"抗辩 → 审查是否构成1222条隐匿拒绝提供
- 期间与时效：时效同基础请求权；注意1222推定情形与举证期限
- 案由对应：医疗损害责任纠纷、环境污染责任纠纷、物件损害责任纠纷（侵权责任纠纷部分）
- 检索口令：举证责任倒置＋过错推定＋1222条病历＋1230条因果关系＋高空坠物1253＋生态侵权证据规定

## 争点：财产保全的申请要件、担保与范围限制
- 请求权基础/抗辩规范：《民事诉讼法》第103、104条（诉讼保全、诉前保全；现行文本序号，T3_043、T4_911均以第103、104条为行为保全与诉前保全依据）＋财产保全规定（T3_005）
- 构成要件树：
  1. 申请书要件（T3_005第1条：身份与送达地址、请求与事实理由、保全数额或争议标的、明确的财产信息或具体线索、担保信息或免担保理由）
  2. 紧迫性／判决难以执行或造成其他损害 —— 因对方行为或其他原因
  3. 担保数额：责令担保的不超过请求保全数额30%；诉前保全应相当于请求保全数额（特殊可酌处）（第5条）；免担保六情形（赡养费扶养费抚恤金等、家暴经济困难、公益诉讼、见义勇为、事实清楚错误可能性小、金融机构）（第9条）；保全责任保险与独立保函（第7、8条）
  4. 范围与方式：限于请求范围或争议财产；超标的禁止；能选对生产经营影响较小财产的影响较小；活封活扣（第13-15条）
  5. 程序：接受申请5日内裁定（紧急48小时）并5日内开始执行（第4条）；诉前保全后30日内起诉自动转诉讼保全（第17条）；查控系统查询申请（第11条）

- 关键司法解释：财产保全规定（T3_005）第1-27条；因申请诉中财产保全损害责任纠纷管辖批复（T3_038）
- 常见抗辩与反击：被保全人对裁定不服→送达5日内向作出法院申请复议一次（第25条，复议停止执行争议）；保全行为违法→按T3_005第26条依民事诉讼法执行行为异议处理；案外人实体异议→第27条＋执行异议之诉
- 期间与时效：诉前保全起诉期30日；续保申请于届满7日前（第18条）
- 案由对应：保全程序随主案由；复议、异议不另立案由
- 检索口令：财产保全＋担保30%＋免担保情形＋48小时＋轮候查封移送＋续封七日＋保全复议

## 争点：行为保全与禁令（人格权禁令、知产行为保全、环境禁止令的程序共通规则）
- 请求权基础/抗辩规范：《民事诉讼法》第103条第1款后段（责令作出一定行为或禁止作出一定行为）＋民法典第997条（人格权禁令，详见04文件节点11）；知产行为保全规定（T3_043）；生态环境侵权禁止令规定（法释〔2021〕22号、经法释〔2026〕16号修正，T4_911）
- 构成要件树：
  1. 胜诉可能性／请求保护的权利稳定性（知产：T3_043第8条考量因素；实用新型外观需检索报告或评价报告——第9条）
  2. 情况紧急与难以弥补的损害：T3_043第6条（不立即保全即足以损害申请人利益）、第10条（商业信誉、市场份额等情形认定）
  3. 利益衡量与公共利益：第7条综合考量是否妨碍被申请人生产经营、损害社会公共利益等
  4. 担保：申请行为保全应依法提供担保（第11条）；一般不因被申请人提供担保解除（第12条）——财产保全可反担保置换（T3_005第22条），行为保全原则上不可
  5. 程序：裁定前询问双方（紧急除外，第5条）；复议10日内审查（第14条）
- 法律效果：责令停止／禁止有关行为；违反的可按民诉法妨害民事诉讼强制措施（第114条现行序号，对应拒不执行判决裁定罪衔接T2_028第12条）
- 关键司法解释：知识产权行为保全规定（法释〔2018〕21号，T3_043）第5-14条；生态环境侵权禁止令保全措施规定（T4_911，援引民事诉讼法第103、104条）；人身安全保护令程序批复（法释〔2016〕15号，T2_048，不收费、不担保、比照特别程序、独任审查）
- 常见抗辩与反击：被申请人以"申请人未担保"抗辩 → 知产、环境禁令须担保，人格权禁令与环境禁止令审查中法院可酌情（T2_048对保护令免担保）；以"本案已败诉风险低"要求解除 → 利益衡量因素逐项回应
- 期间与时效：诉前保全后30日内起诉（衔接T3_005第17条）；保全期限由法院合理确定（T3_043第13条）
- 案由对应：482.申请人格权侵害禁令、481.申请人身安全保护令；知产/环境禁令随主案由
- 检索口令：行为保全＋难以弥补的损害＋情况紧急＋询问被申请人＋担保＋人格权禁令＋环境禁止令＋拒不执行裁定罪

## 争点：申请保全错误的损害赔偿责任与管辖
- 请求权基础/抗辩规范：《民事诉讼法》第105条（2012文本序号："申请有错误的，申请人应当赔偿被申请人因保全所遭受的损失"；现行文本序号有迁移，批复按原序号援引）＋民法典第1165条一般侵权构成
- 构成要件树：
  1. 保全申请存在错误：败诉结果不当然等于错误，审查请求是否具合理基础、是否存在故意或重大过失
  2. 损失：利息、经营损失、处置受限损失
  3. 因果关系
  4. 案外人受损：申请保全错误造成案外人损失的应予赔偿（保全错误案外人损失解释）
- 法律效果：侵权损害赔偿之诉
- 关键司法解释：因申请诉中财产保全损害责任纠纷管辖批复（法释〔2017〕14号，T3_038）：由作出诉中保全裁定的法院管辖；当事人申请财产保全错误造成案外人损失应否承担赔偿责任的解释（法释〔2005〕11号，T3_054）：应当赔偿；保全规定（T3_005）第23条（应当申请解除保全而未及时解除致损的赔偿）
- 常见抗辩与反击：申请人以"保全金额未超诉请"抗辩 → 结合胜诉率、可预见性判断"错误"；被申请人未及时采取减损措施 → 过失相抵（591条参照）
- 期间与时效：3年，自保全被撤销或本案裁判生效知损时起算
- 案由对应：因申请诉中财产保全损害责任纠纷（侵权责任纠纷部分）
- 检索口令：保全错误损害赔偿＋管辖批复2017＋案外人损失＋未及时解除保全＋过失相抵

## 争点：执行依据与申请执行期间（两年、中止中断与超期受理）
- 请求权基础/抗辩规范：《民事诉讼法》申请执行期间规定（两年，适用诉讼时效中止中断规定——民诉法解释第466条援引"民事诉讼法第二百四十六条"即该条）＋执行依据效力（生效判决、裁定、调解书、仲裁裁决、公证债权文书等）
- 构成要件树：
  1. 期间起算：法律文书规定履行期间最后一日；分期履行自每次履行期届满；未定履行期间自文书生效之日
  2. 中止：申请执行时效最后六个月内因不可抗力等不能行使请求权的中止（执行程序解释（T3_071）第19条）
  3. 中断：申请执行、双方达成和解协议、一方提出履行要求或同意履行义务（第20条）；不作为义务自违反之日（第21条）
  4. 超期后果：法院应予受理；被执行人提出异议经审查成立→裁定不予执行；履行后不得以不知超期请求回转（民诉法解释第481条）
  5. 恢复执行原生效法律文书适用申请执行期间规定，自执行和解协议约定履行期限最后一日起重新计算（民诉法解释第466条、T3_003第10条）
- 法律效果：不予执行裁定；已履行部分不回转
- 关键司法解释：执行程序解释（T3_071）第19-21条；民诉法解释第466、481条；执行和解规定（T3_003）第10条
- 常见抗辩与反击：被执行人以"超两年"抗辩 → 举证催告、部分受领、和解磋商记录证明中断；以中止执行裁定为由抗辩期间冻结 → 中止执行期间依法不计为怠于行使
- 期间与时效：2年（性质为时效，可中止中断，非除斥）
- 案由对应：执行案件；异议之诉另列
- 检索口令：申请执行时效＋两年＋中止中断＋和解重新计算＋超期受理＋不予执行异议

## 争点：执行异议之类型区分——执行行为异议与案外人标的异议
- 请求权基础/抗辩规范：《民事诉讼法》执行行为异议条款（当事人、利害关系人认为执行行为违反法律规定，T3_005第26条、T3_016第2条援引"民事诉讼法第二百二十五条"即2021文本第232条、现行第236条）；案外人标的异议（民事诉讼法第238条，2025年执行异议之诉解释援引序号）
- 构成要件树：
  1. 行为异议：针对查封、冻结、评估、拍卖、终结措施等程序违法 → 书面异议→15日内裁定→不服的向上一级法院申请复议（复议期间不停止执行）
  2. 提出时点：执行程序终结前（对终结执行措施异议除外）（T3_016第6条）
  3. 案外人异议：对执行标的主张实体权利排除执行 → 由负责执行该标的法院审查（T3_002第1条）；审查期立案3日内＋通知（T3_016第2条）
  4. 分流：与原判决裁定无关→15日内提执行异议之诉；认为原裁判错误→申请再审或提第三人撤销之诉（民诉法解释第301条第2款：案外人对驳回裁定不服且认为原裁判内容错误的应申请再审，提三撤不予受理）
- 法律效果：中止执行／驳回／进入诉讼
- 关键司法解释：执行异议和复议规定（T3_016）第2、6条；财产保全规定（T3_005）第26、27条（保全实施中的行为异议与案外人实体异议分流）；执行异议之诉解释（法释〔2025〕10号，T3_002）第1条
- 常见抗辩与反击：以"应提异议之诉而提行为异议"管辖抗辩 → 按异议对象性质重新定性告知；保全案件案外人误提复议 → T3_005第27条导入异议之诉
- 期间与时效：异议裁定送达后15日起诉期（不变期间）
- 案由对应：案外人执行异议之诉、申请执行人执行异议之诉（特殊诉讼程序案件案由）
- 检索口令：执行行为异议＋案外人异议＋复议与诉讼分流＋15日＋238条＋232条

## 争点：案外人执行异议之诉的排除执行权益与继续执行担保（2025年新解释）
- 请求权基础/抗辩规范：执行异议之诉解释（法释〔2025〕10号）第1条（受理与起诉期）、第3-5条（排除执行判决＋确权、给付请求合并）、第6条（审理期间申请执行人担保继续执行的处理三情形）、第11-20条（商品房消费者、不动产买受人、以物抵债、预告登记、租赁等实体排除标准）、第22条（申请执行人异议之诉参照）
- 构成要件树：
  1. 当事人结构：轮候查封场景以下首先查封、优先受偿权保全人/申请执行人为被告，其他轮候者为第三人（第2条）；确权请求以被执行人为被告（第4条）
  2. 商品房消费者排除执行三要件（第11条：查封前合法有效书面买卖合同；查封前付清全款或部分价款且一审辩论终结前交付剩余价款执行；用于家庭居住生活需要）
  3. 一般不动产买受人四要件（第14条：查封前合同＋价款付清或补足＋合法占有＋非因自身原因未登记）；"非因自身原因"六情形（第16条）
  4. 以物抵债排除执行要件（第15条：真实到期债权＋查封前抵债协议＋价格基本相当＋占有＋非因自身原因未过户）；工程款折抵（第17条，衔接民法典第807条）；征收补偿安置房（第18条）；预告登记（第19条）；在先租赁排除带租处分（第20条）
  5. 虚假诉讼制裁：恶意串通伪造证据妨害执行→驳回＋罚款拘留＋移送＋赔偿（第21条）
- 法律效果：判决不得执行该执行标的并同时判决解除执行措施、写明查封裁定案号（第3条）；继续执行担保的按第6条三种走向处理；执行案件结案且措施解除→终结诉讼（第7条）；被执行人破产→中止（第9条）
- 关键司法解释：法释〔2025〕10号第1-23条；衔接民诉法解释第301-307条、第314条（申请执行人未起诉的15日后7日内解除执行措施）
- 常见抗辩与反击：申请执行人主张买受人"查封后才补足价款"→ 第14条第2项明确允许"查封后至一审法庭辩论终结前"交付执行，属新解释扩张；被执行人与案外人亲属关系+资金回流证据指向虚假
- 期间与时效：自执行异议裁定送达之日起15日内起诉；再审适用审判监督程序（第10条）
- 案由对应：案外人执行异议之诉；申请执行人执行异议之诉
- 检索口令：执行异议之诉＋法释〔2025〕10号＋足以排除强制执行的民事权益＋商品房消费者＋非因自身原因＋交付剩余价款＋担保继续执行

## 争点：执行中变更、追加被执行人与执行异议之诉的救济分流
- 请求权基础/抗辩规范：变更追加当事人规定（T3_059）第1条（法定主义：申请符合法定条件）、第2-27条（各事由）、第30-34条（复议与异议之诉分流）
- 构成要件树：
  1. 申请人侧变更：自然人死亡→遗产管理人、继承人、受遗赠人（第2条，与继承编衔接）；离婚分得权利配偶（第3条）；法人合并分立清算（第4-7条）；债权转让＋书面认可（第9条）
  2. 被执行人侧追加：死亡被执行人之遗产范围内担责主体（第10条）；个人独资出资人（第13条）；普通合伙人、未按期足额出资有限合伙人（第14条）；分支机构与法人互执（第15条）；未足额出资股东、抽逃出资股东、瑕疵转让股权的原股东（第17-19条）；一人公司股东不能证明财产独立（第20条，公司法举证责任衔接）；未经清算注销的股东董事控股股东（第21条）；接受无偿财产的出资人主管部门（第22条）；第三人承诺代偿（第23-24条）；行政划转受让人（第25条）
  3. 程序：书面申请＋听证（除简单案件），60日内裁定（第28条）；审查期间可参照民诉法保全规定查封冻结（第29条）
  4. 救济分流：对追加裁定不服→10日内向上一级法院复议（第30条）；但对依第14条第2款、第17-21条（出资瑕疵与清算责任类）裁定不服→15日内向执行法院提执行异议之诉（第32条），诉讼期间不得处分争议财产（第31、33条）
- 法律效果：变更、追加裁定生效；异议之诉判决"不得变更追加或变更责任范围"（第33条）
- 关键司法解释：T3_059全文；关联执行异议之诉解释（法释〔2025〕10号）第22条参照路径；追加后债务人抗辩重复责任禁止（第26条）
- 常见抗辩与反击：被追加股东以"出资已实缴"抗辩 → 举证验资、审计与银行流水；一人公司股东财产独立举证责任在股东（第20条）；以"已过复议期"抗辩异议之诉 → 核查是否属第32条应诉情形
- 期间与时效：复议10日／诉讼15日；均自裁定送达起算
- 案由对应：被执行人追加、变更异议之诉（2025年案由规定特殊诉讼程序部分）
- 检索口令：追加被执行人＋法定主义＋未足额出资股东＋一人公司财产混同＋复议十日＋异议之诉十五日＋32条分流

## 争点：参与分配的条件、顺位与方案异议之诉
- 请求权基础/抗辩规范：民诉法解释第506条（被执行人为公民或其他组织，执行开始后其他已取得执行依据的债权人发现财产不能清偿所有债权→申请参与分配；对查封财产有优先权、担保物权的债权人可直接申请并主张优先受偿）、第507条（申请书＋执行依据；财产执行终结前提出）、第508条（价款扣除执行费用、清偿优先债权后，普通债权原则上按比例受偿；剩余债务继续清偿，发现新财产可随时请求执行）、第509条（分配方案＋15日内书面异议）
- 构成要件树：
  1. 主体：被执行人为公民或其他组织（企业法人资不抵债应走破产程序，未经清理变价不得参与分配的除外衔接破产法解释）
  2. 时点：执行程序开始后、被执行人财产执行终结前
  3. 方案异议与诉讼：收到分配方案15日内书面异议（第509条）→法院通知未异议的债权人、被执行人→其提出反对意见的通知异议人→异议人15日内以反对者为被告向执行法院提起分配方案异议之诉；逾期未诉按原方案分配，诉讼期间争议债权数额相应款项提存（第510条）
- 法律效果：按普通债权比例受偿；优先债权先行扣除
- 关键司法解释：民诉法解释第506-510条（参与分配节；第511条以下为执行转破产衔接）；首先查封法院与优先债权执行法院处分查封财产批复（T3_074）
- 常见抗辩与反击：首封债权人以"处置权在我"排斥参与分配 → 处置权与分配权分离；担保债权人未申报直接主张优先 → 允许（第506条第2款）但须在程序中及时提出
- 期间与时效：财产执行终结前提出；方案异议收到后15日
- 案由对应：分配方案异议之诉（特殊诉讼程序案件案由）
- 检索口令：参与分配＋公民其他组织＋按比例受偿＋担保物权直接申请＋分配方案异议之诉＋执行终结前

## 争点：执行和解的效力、不履行之救济选择与恢复执行
- 请求权基础/抗辩规范：执行和解规定（T3_003）第1条（可变更权利义务主体、履行标的、期限、地点、方式）＋民诉法解释第464条（达成和解后请求中止或撤回申请的处理）
- 构成要件树：
  1. 中止执行三形式（共同提交书面协议／一方提交他方认可／口头记入笔录签章）（第2条）
  2. 不得依据以物抵债和解协议作出以物抵债裁定（第6条）
  3. 不履行之选择权：申请恢复执行原生效法律文书，或就履行和解协议向执行法院提起诉讼（第9条）；恢复后不得再诉履行（第13条）；起诉后受理可裁定终结原执行、查封冻结转诉讼保全（第14条）
  4. 恢复执行阻却：履行完毕、期限未届条件未成（预期违约除外——第578条，第11条第2项）、正在履行（第11条）
  5. 和解协议无效或可撤销之诉（第16条）；代理人特别授权（第4条）
  6. 恢复后已履行部分扣除（第17条）；担保条款＋自愿接受直接执行承诺→恢复后可直接裁定执行担保财产（第18条）
  7. 未提交法院的私下和解：按执行行为异议处理（第19条五种裁定走向）
- 法律效果：中止/恢复/终结执行；和解协议另生诉权
- 关键司法解释：T3_003第1-19条；民诉法解释第464、466条
- 常见抗辩与反击：被执行人以"已达成和解"阻却恢复 → 核履行进度与期间未届抗辩；申请执行人同时申请恢复并起诉履行 → 择一行使，恢复在先则不予受理
- 期间与时效：恢复执行适用申请执行时效，自和解协议约定履行期最后一日重新计算（第10条；民诉法解释第466条）
- 案由对应：执行和解协议纠纷（合同纠纷部分）；执行异议复议程序
- 检索口令：执行和解＋恢复执行＋就履行和解协议起诉＋以物抵债不得裁定＋履行完毕扣除＋担保条款直接执行

## 争点：执行担保、暂缓执行与担保期间
- 请求权基础/抗辩规范：执行担保规定（T3_009）第1条（依民事诉讼法执行担保条款向法院提供担保）、第8、10-13条
- 构成要件树：
  1. 形式：被执行人或他人财产担保／保证；提交担保书并副本送申请执行人；载明自愿接受直接强制执行承诺（第3、4条）；公司为被执行人担保须章程＋决议（第5条，公司法第16条衔接）
  2. 申请执行人书面同意（第6条）→ 法院决定暂缓执行（第8条），期限与约定一致且最长不超过1年（第10条）
  3. 恢复并直接执行：暂缓期满不履行或担保人转移毁损担保财产→依申请恢复执行，直接裁定执行担保财产或保证人财产，不得将担保人变更追加为被执行人（第11条）
  4. 担保期间：自暂缓期满起算；未记载或不明为1年；期满申请执行不予支持（第12、13条）
  5. 担保书内容不实影响权益→恢复执行（第9条）；登记公示后申请执行人可主张优先受偿（第7条）；担保人承担责任后可诉请追偿（第14条）
- 法律效果：暂缓执行＋直接执行担保财产（责任财产以应履行部分为限；被执行人有现金存款优先执行——第11条第2款）
- 关键司法解释：T3_009第1-15条（第15条参照适用于"申请解除执行措施并担保履行"情形）
- 常见抗辩与反击：保证人以"未约定担保期间已超期"抗辩→ 适用第12条默认1年；申请执行人主张追加担保人为被执行人→ 第11条明文禁止，只能执行其责任财产
- 期间与时效：担保期间1年（除斥性质）；暂缓执行≤1年
- 案由对应：执行程序内；追偿另诉（保证合同/追偿权纠纷）
- 检索口令：执行担保＋暂缓执行一年＋直接执行担保财产＋不得追加担保人＋担保期间一年＋公司决议

## 争点：迟延履行期间债务利息的计算与清偿顺序
- 请求权基础/抗辩规范：《民事诉讼法》迟延履行加倍利息条款（迟延履行利息解释第1条援引"民事诉讼法第二百五十三条"即现行加倍支付迟延利息规定）＋迟延履行利息解释（法释〔2014〕8号，T3_056）
- 构成要件树：
  1. 构成：一般债务利息（按生效文书确定方法计算；文书未确定的不计算）＋加倍部分债务利息（尚未清偿的除一般债务利息之外的金钱债务×日万分之一点七五×迟延履行期间）
  2. 起算：文书确定履行期届满之日；分期履行自每次届满；未定履行期自文书生效之日（第2条）
  3. 截止：履行完毕之日；划扣日、拍卖成交或抵债裁定生效日、其他变价完成日（第3条）；非因被执行人申请的审查中止、暂缓及再审中止期间不计加倍利息（第3条第3款）
  4. 清偿顺序：财产不足清偿全部债务→先清偿文书确定金钱债务，再清偿加倍部分利息，另有约定除外（第4条）
  5. 外币按日万分之一点七五计（可主张人民币折算，第5条）；执行回转中原申请执行人迟延亦承担（第6条）
- 法律效果：加倍部分利息属惩罚性债权，随执行程序收取
- 关键司法解释：T3_056第1-7条；法释〔2009〕6号（T3_039）用于2014年8月1日前迟延履行期间的旧标准衔接（第7条）
- 常见抗辩与反击：被执行人以"判决未写明利息"主张免除一般债务利息 → 加倍部分法定不因文书未载而消灭；中止执行期间利息争议 → 区分中止动议主体
- 期间与时效：迟延利息计算至实际清偿日；申请执行时效及于该债权
- 案由对应：执行案件
- 检索口令：迟延履行利息＋日万分之一点七五＋加倍部分债务＋清偿顺序＋执行中止不计＋执行回转

## 争点：既判力——重复起诉的识别与生效裁判确认事实的免证
- 请求权基础/抗辩规范：民诉法解释第247条（重复起诉三同：当事人相同、诉讼标的相同、诉讼请求相同或后诉实质否定前诉裁判结果；裁判生效后再次起诉的裁定不予受理、已受理的驳回起诉，但发生新的事实的除外）；第93条（生效裁判确认的基本事实免证，当事人有相反证据足以推翻除外）
- 构成要件树：
  1. 前诉是否已"裁判"生效并覆盖本诉标的（调解书同样具既判力参照）
  2. 请求权基础竞合但诉讼标的不同（如违约与侵权）是否构成实质否定
  3. "新的事实"例外：裁判生效后发生的清偿、抵销、迟延利息等
  4. 既判力对后诉法官的拘束：免证事实＋禁止矛盾（第93条）
- 法律效果：不予受理／驳回起诉（裁定）；免证效力
- 关键司法解释：民诉法解释第247、248条（新事实除外）；第93条；关联第三人撤销之诉（第292、295、297、299、301条）与案外人异议分流（05文件前述节点）
- 常见抗辩与反击：原告以"换了被告/请求权"规避 → 审查实质否定标准；被告以生效裁判免证直接引用 → 核对是否属"基本事实"且无相反证据
- 期间与时效：不适用（程序审查）
- 案由对应：全案由；离婚案件"没有新情况新理由六个月内不得再起诉"为特别规定（对照T2_028第11条新情况认定）
- 检索口令：重复起诉＋三同＋实质否定裁判结果＋新的事实除外＋免证事实＋第三人撤销之诉衔接

## 争点：再审申请——事由、期限、主体限制与提审发回
- 请求权基础/抗辩规范：《民事诉讼法》再审事由条款（2021文本第200、205、206条，现行文本序号迁移；民诉法解释与审判监督解释按其援引序号适用）＋审判监督解释（T3_070）＋指令再审发回重审规定（法释〔2015〕7号，T3_058）
- 构成要件树：
  1. 期限：判决、裁定生效后六个月内提出；再审事由系新证据出现、据以作出原裁判的法律文书被撤销或变更、审判人员贪污受贿枉法裁判等情形的，自知道或应当知道之日起六个月内（民诉法解释第399条语境）
  2. 事由审查围绕第200条（现对应条）十三项＋调解书损害国家利益社会公共利益；"新证据"须能证明原判决基本事实或裁判结果错误（T3_001第385条）；"未经质证"排除原审拒绝质证情形（第387条）；"适用法律确有错误"六种（第388条）；"剥夺辩论权利"情形（第389条，含未经合法传唤缺席）
  3. 不予受理：再审申请被驳回后再次申请、对再审判决裁定提出申请、检察院作出不予提出再审检察建议或抗诉决定后再申请的（T3_001第381条）；解除婚姻关系的判决、调解书不得申请再审（民事诉讼法特别规定）；涉身份关系的生效文书内容亦属第三人撤销之诉不予受理情形（第295条第2项）；申请超期或超出法定事由范围的裁定驳回（T3_070第11条）
  4. 提审与指令再审：符合第(4)(5)(9)项等情形可指令原审再审；再审系原审法院再审后作出、经审委会讨论、审判人员贪腐、无再审管辖权、需统一法律适用等→应当提审（T3_058第2、3条）；依院长发现＋审委会裁定再审的应当提审（第2条第3款）
  5. 发回重审限定：原判决认定事实错误不得以"基本事实不清"发回（T3_058第4条）；严重违反法定程序五情形可发回一审（第5条）
- 法律效果：裁定再审并中止执行（再审裁定中写明中止原判决执行，T3_001第394条）；再审围绕再审请求审理，超原审诉请不予审理（T3_058第7条）
- 关键司法解释：T3_070第8条（围绕事由审查）、第11条（超期或超范围裁定驳回）；T3_058第1-9条；民诉法解释第381、385、387-390、394、399条
- 常见抗辩与反击：被申请人以"超六个月"抗辩 → 核起算点是否属"知道之日"事由；以"已经再审"阻却再申请 → 第381条；诉讼时效抗辩不得作为再审新事由（T1_010第3条第2款）
- 期间与时效：6个月（不变期间）；检察监督衔接另册
- 案由对应：再审审查与审判监督案件随原审案由
- 检索口令：再审事由＋六个月＋新证据＋指令再审＋提审＋发回重审限定＋解除婚姻关系不得再审

## 争点：仲裁协议效力认定与司法审查程序
- 请求权基础/抗辩规范：《仲裁法》第16、17、20条（书面形式、无效情形、效力异议由仲裁委或法院决定且法院优先）＋仲裁法解释（法释〔2006〕7号，T3_069）＋仲裁司法审查规定（法释〔2017〕22号，T3_044）
- 构成要件树：
  1. 书面形式扩张：合同书、信件、数据电文（电报电传传真电子数据交换电子邮件）（T3_069第1条）
  2. 仲裁事项概括约定"合同争议"→成立、效力、变更、转让、履行、违约责任、解释、解除纠纷均属之（第2条）
  3. 机构瑕疵：名称不准确但可确定→有效（第3条）；仅约定仲裁规则→未约定机构（第4条）；约定两个以上机构且不能达成一致→无效（第5条）；约定某地仲裁机构该地仅一个→有效（第6条）
  4. 或裁或审：既约定仲裁又约定起诉→无效，但一方申请仲裁另一方未在仲裁庭首次开庭前异议的除外（第7条＋仲裁法第20条第2款）
  5. 主体承继：合并分立、死亡对继受人有效（第8条）；债权债务转让对受让人有效，但有约定、明确反对或不知有单独仲裁协议除外（第9条）
  6. 合同不成立/未生效/被撤销不影响仲裁条款（仲裁法第19条；第10条）；援引其他合同仲裁条款有效（第11条）
  7. 异议权失权：首次开庭前未异议，事后向法院申请确认无效不予受理（第13条）
- 法律效果：仲裁条款独立性＋法院确认之诉裁定
- 关键司法解释：T3_069第1-16条；T3_044第1条（仲裁司法审查案件范围）、第2条（确认仲裁协议效力案件管辖：约定机构所在地、签订地、申请人住所地、被申请人住所地中院或专门法院）、第13-15条（涉外仲裁协议准据法的选择与"有效解释"取向）、第20条（除不予受理、驳回申请、管辖权异议裁定外一经送达即生效，不得复议上诉再审）；民法典第507条（争议解决条款独立性）
- 常见抗辩与反击：被告以"合同未盖章仲裁条款无效"抗辩 → 主合同成立与仲裁条款效力二分（T3_069第10条）；以"已向仲裁庭提异议"阻却法院确认 → 核异议时点（第13条首次开庭界限）
- 期间与时效：确认之诉无期间限制，但受首次开庭前异议规则拘束；申请执行/撤销裁决期间见下节点
- 案由对应：申请确认仲裁协议效力（非讼程序案件案由，仲裁司法审查类别）
- 检索口令：仲裁协议效力＋或裁或审＋机构约定不明＋首次开庭前异议＋独立性＋法释2017年22号管辖

## 争点：撤销仲裁裁决与不予执行仲裁裁决的双轨审查
- 请求权基础/抗辩规范：《仲裁法》第58条（撤销事由＋6个月期间）、第63条（不予执行事由即民诉法仲裁裁决不予执行条款）＋不予执行仲裁裁决司法解释衔接
- 构成要件树：
  1. 撤销程序：组成合议庭审理并询问当事人（T3_069第24条）；事由法定（无仲裁协议——含协议无效或被撤销视为无协议（第18条）；超裁部分可撤，不可分则全撤（第19条）；"违反法定程序"限于可能影响正确裁决（第20条）；仲裁员索贿受贿枉法裁判须生效刑事文书或纪律处分确认（T3_044第18条））
  2. 重新仲裁：伪造证据或隐瞒关键证据情形可通知仲裁庭重新仲裁，开始后终结撤销程序（T3_069第21、22条；对重裁裁决不服6个月内可申请撤销——第23条）
  3. 与执行的衔接：受理撤销申请后另一方申请执行→中止执行（第25条）；撤销申请被驳回后以相同理由抗辩不予执行→不支持（第26条）；仲裁程序中未异议事后主张→不支持（第27条）；仲裁调解书与依和解协议所作裁决不得申请不予执行（第28条；仲裁裁决执行规定（T3_015）第17条同旨并扩展案外人申请）
  4. 不予执行细化：仲裁裁决执行规定（T3_015）第2条（被执行人申请不予执行）、第7条（撤销申请受理期间中止执行）、第9条（案外人申请不予执行）、第13-16条（隐瞒证据、违反法定程序、超范围仲裁的认定）
  5. 管辖与生效：执行仲裁裁决由被执行人住所地或财产所在地中院管辖（T3_069第29条）；司法审查裁定救济限制（T3_044第20条）
- 法律效果：撤销裁定／不予执行裁定；驳回申请后原裁决继续执行
- 关键司法解释：T3_069第17-29条；T3_044第17、18、20条；T3_015第2、7、9、13-20条；撤销仲裁裁决程序批复（法释〔1998〕16号，T3_045）
- 常见抗辩与反击：以"认定事实错误"申请撤销 → 法院不审实体，限于法定事由（第17条：事由外申请不支持）；被执行人双轨并用（先撤后抗）→ 第26、27条失权规则拦截
- 期间与时效：撤销申请自收到裁决书之日起6个月；不予执行申请在执行程序中提出（T3_015第19条逾期申请的处理）
- 案由对应：申请撤销仲裁裁决；申请不予执行仲裁裁决（仲裁司法审查类）
- 检索口令：撤销仲裁裁决六个月＋不予执行＋重新仲裁＋案外人不予执行＋超裁不可分＋失权

## 争点：诉讼费用与保全费用的负担、退补与司法救助
- 请求权基础/抗辩规范：《诉讼费用交纳办法》（国务院令第481号，未入库本语料，适用时另行核验）＋民诉法解释"诉讼费用"节（第195、196、199、203、207条）
- 构成要件树：
  1. 败诉负担与部分胜诉按比例（第203条：连带责任人共同负担）
  2. 退费：胜诉方预交但不应负担的诉讼费法院应退还，由败诉方向法院交纳（第207条第1款；胜诉方自愿承担或同意的除外）
  3. 支付令转诉讼：按《交纳办法》补交受理费（第195条）
  4. 简易转普通：接到交费通知7日内补交，逾期按撤诉处理，已收费用退一半（第199条）
  5. 保全申请费：由申请人在提出申请时负担（交纳办法第10条口径，语料缺位须外查）；调解结案的减半负担
  6. 免交与救助：人身安全保护令不收费（保护令批复T2_048第1项）；不担保（第2项）
  7. 裁判文书应一并处理诉讼费负担；二审改变结果的同步调整（第196条）
- 法律效果：费用负担入判决主文；不预交按撤诉/不予受理处理
- 关键司法解释：T3_001第195、196、199、203、207条；T2_048；《交纳办法》未入库——引用前以现行文本核验
- 常见抗辩与反击：胜诉方请求对方直接向其支付垫付费用 → 原则由法院退收分离，当事人另有合意除外（第207条第1款但书）

## 争点：2025-2026年程序新件对家事与准合同案由、禁令路径的影响
- 请求权基础/抗辩规范：案由规定（法〔2025〕226号修改、法〔2025〕227号印发，自2026年1月1日起施行）对案由体系与程序路径的重塑
- 构成要件树：
  1. 准合同案由升格：不当得利纠纷（148）、无因管理纠纷（149）自2020年版本即列"合同、准合同纠纷"部分，2025年文本沿用，检索时以"第四部分"定位
  2. 非讼程序新增案由：481.申请人身安全保护令、482.申请人格权侵害禁令（第51、52类非讼案由）——民法典第997条自此有独立立案通道，与行为保全（诉讼中申请）并行择用
  3. 445.申请指定遗产管理人（非讼）支撑民法典第1146条
  4. 一级案由扩为12部分，新设"数据、网络虚拟财产纠纷"（十八、网络虚拟财产纠纷），虚拟财产继承、侵害之诉获得直接案由
  5. 侵权案由优先规则：第4部分适用说明明确"先适用第十部分侵权责任纠纷项下具体案由，无对应再适用人格权纠纷等部分"——竞合检索时注意
  6. 与婚姻家庭编解释（二）（法释〔2025〕1号）第12条配套：抢夺藏匿未成年子女禁令案由此前"比照行为保全"转向482号案由直接立案
  7. 与执行异议之诉解释（法释〔2025〕10号）衔接：执行异议之诉仍列特殊诉讼程序案由
