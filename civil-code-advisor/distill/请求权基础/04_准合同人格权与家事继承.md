# 请求权基础路由 04：准合同、人格权、婚姻家庭与继承

> 覆盖民法典第979-988条（无因管理、不当得利）、第989-1039条（人格权编）、第1040-1118条（婚姻家庭编）、第1119-1163条（继承编）核心争点，及《总则编解释》（法释〔2022〕6号）、《婚姻家庭编解释（一）》（法释〔2020〕22号）、《婚姻家庭编解释（二）》（法释〔2025〕1号）、《继承编解释（一）》（法释〔2020〕23号）、《涉彩礼纠纷规定》（法释〔2024〕1号）、《精神损害赔偿解释》（2020修正）、《人脸识别解释》（法释〔2021〕15号）、《网络侵害人身权益解释》（2020修正）、《人身安全保护令规定》（法释〔2022〕17号）、《侵权责任编解释（一）》（法释〔2024〕12号）、《时间效力规定》（法释〔2020〕15号）、《案由规定》（法〔2025〕226号修改，2026-01-01施行）。
> 条文序号约定：民法典条号依语料原文；解释条文按各文件现行文本逐条引用；《民事诉讼法》仅在有语料锚点处引用条号。

## 争点：不当得利返还请求权是否成立（给付型与非给付型的审查路径）
- 请求权基础/抗辩规范：民法典第985条（受损失的人的返还请求权）；第987条（恶意得利人的加重返还）
- 构成要件树：
  1. 一方取得利益（财产总额增加或应减少而未减少）—— 证明责任：原告
  2. 他方受有损失 —— 原告
  3. 取得利益没有法律根据（给付型：给付目的不达、目的消灭、目的自始不存在；非给付型：权益侵害型、费用支出型、求偿型）—— 原告就"无法律根据"证明，给付型中可通过证明基础关系不存在/无效/被撤销完成初步证明，由得利人举证存在保有依据
  4. 反驳路径：得利人主张存在合同、判决、遗产归属等保有依据（第985条反面解释）
- 法律效果：返还所取得的利益（原物、孳息、价额）；恶意得利人另依第987条赔偿损失
- 关键司法解释：诉讼时效规定（T1_010）第6条——返还不当得利请求权时效自"知道或应当知道不当得利事实及对方当事人之日"起算；合同编通则解释（T1_002）第51条——第三人加入债务后无追偿权约定时依不当得利等规定向债务人求偿
- 常见抗辩与反击：得利人以"对方明知无给付义务"抗辩（第985条第3项）→ 原告举证给付时对义务存在有合理信赖或系误认，误认非"明知"
- 期间与时效：3年（第188条），自知道或应当知道不当得利事实及对方当事人之日起算（T1_010第6条）
- 案由对应：民事案件案由规定（2025修改）第四部分"合同、准合同纠纷"之"十一、不当得利纠纷"（148.不当得利纠纷）
- 检索口令：不当得利＋没有法律根据＋给付目的＋985＋时效起算

## 争点：不当得利请求权的排除情形（四类排除的审查顺序）
- 请求权基础/抗辩规范：民法典第985条但书第1-3项＋第986条（善意得利人免返还），构成实务所称"四类排除"
- 构成要件树：
  1. 为履行道德义务进行的给付（如未经法定扶养义务自愿扶养、礼仪性给付）—— 得利人举证给付属道德义务范畴
  2. 债务到期之前的清偿（第985条第2项）—— 期限利益抛弃，不得请求返还
  3. 明知无给付义务而进行的债务清偿（第985条第3项）—— 得利人证明对方"明知"
  4. 善意得利人利益已不存在（第986条）—— 得利人证明"不知道且不应当知道"＋利益不存在（消费灭失），仅在现存利益范围内负责
- 法律效果：排除第985条返还请求权或免负返还义务
- 关键司法解释：诉讼时效规定（T1_010）第6条（排除情形争议中的时效仍自知道事实及对方之日起算）
- 常见抗辩与反击：给付人以"重大误解"主张撤销给付再索回 → 撤销权受第152条除斥期间限制（重大误解90日），且被撤销前给付有法律根据；注意与民间借贷已付超限利息的返还争议区分
- 期间与时效：第985条3年；主张撤销基础关系的除斥期间见第152条
- 案由对应：148.不当得利纠纷（2025年案由规定）
- 检索口令：不当得利＋排除＋道德义务给付＋到期前清偿＋明知无给付义务＋善意得利人＋986

## 争点：不当得利返还范围与对第三人（无偿受让人）的返还请求
- 请求权基础/抗辩规范：民法典第986条（善意——以现存利益为限）、第987条（恶意——返还利益＋依法赔偿损失）、第988条（无偿受让第三人在相应范围内承担返还义务）
- 构成要件树：
  1. 善意/恶意的判断时点：取得利益时"不知道且不应当知道"为善意（第986条）；知道或应当知道为恶意（第987条）—— 主张恶意方举证
  2. "取得的利益已经不存在"—— 得利人举证财产总额未因得利而增加
  3. 第988条：得利人无偿转让＋第三人无对价保有 —— 原告证明转让无偿性
- 法律效果：善意免返或现存利益返还；恶意全额返还并赔偿损失；第三人承担范围内返还义务（与得利人不免除责任并存时以受偿总额不超过损失为限）
- 关键司法解释：合同编通则解释（T1_002）第24条（合同不成立、无效、被撤销或确定不发生效力时的财产返还方式与折价补偿基准日，可参照确定返还范围）；总则编解释（T1_004）第23条（民事法律行为不成立时参照第157条）
- 常见抗辩与反击：得利人主张已缴纳税费、支付成本应扣减 → 仅现存利益可扣，恶意得利人不得主张费用扣减（第987条反面）
- 期间与时效：同第985条3年；对第988条第三人的请求权时效自知道该无偿转让之日起算（类推T1_010第6条）
- 案由对应：148.不当得利纠纷
- 检索口令：不当得利＋返还范围＋现存利益＋恶意得利人＋无偿转让第三人＋988

## 争点：合同无效（被撤销、不成立、确定不发生效力）后果与不当得利的规范关系
- 请求权基础/抗辩规范：民法典第157条（返还财产、折价补偿、过错赔偿）为特别效果规范；第985条一般补充
- 构成要件树：
  1. 民事法律行为无效/被撤销/确定不发生效力 —— 主张方举证无效事由（第144、146、153、154条等）
  2. 因该行为取得财产 —— 给付事实＋因果关系
  3. 不能返还或没有必要返还 → 折价补偿（替代返还）
  4. 损失赔偿：以过错为要件，各方都有过错的各自承担相应责任
- 法律效果：返还义务自无效判决确定时回溯至行为成立时点（第155条自始无约束力）；资金占用费按LPR计算（无过错方按存款基准利率）
- 关键司法解释：合同编通则解释（T1_002）第24条（返还方式：返还占有标的物、更正登记簿册；折价补偿以认定不成立/无效/被撤销/不发生效力之日的市场价值为基准）、第25条（资金占用费LPR标准、双方互负返还义务的同时履行与抵销）；总则编解释（T1_004）第23条（不成立参照第157条）
- 常见抗辩与反击：受领人以"合同已履行完毕"抗辩返还 → 无效合同自始无约束力，履行完毕不免返还；对缔约过失赔偿，双方过错相抵
- 期间与时效：合同被撤销后返还财产、赔偿损失请求权时效自"合同被撤销之日"起算（T1_010第5条第2款）；主张无效之诉本身不受诉讼时效限制，但返还请求权受3年限制
- 案由对应：按基础关系定案由（如合同纠纷、确认合同无效纠纷），单列返还之诉时可用148.不当得利纠纷
- 检索口令：157条＋折价补偿＋合同无效后果＋资金占用费＋合同编通则解释24条25条＋不当得利关系
- 备注：第157条与第985条竞合时优先适用第157条（有特别规范），不得绕过合同效力审查径行主张不当得利

## 争点：超限利息返还、彩礼返还与不当得利的竞合边界
- 请求权基础/抗辩规范：民法典第680条（禁止高利放贷，利率不得违反国家有关规定）＋民间借贷利率上限（T2_011第25、28、29条）；第1042条第1款（禁止借婚姻索取财物）＋彩礼返还特别规则（T2_033第5、6条；T1_003第5条）；不当得利（第985条）仅为兜底
- 构成要件树：
  1. 已付利息超过合同成立时一年期LPR四倍 —— 借款人举证付款事实与利率
  2. 彩礼：以婚姻为目的依习俗给付（T2_033第3条排除日常消费性支出、小额礼物）；未登记/登记未共同生活/给付致生活困难（T1_003第5条）或已登记但共同生活时间较短且数额过高（T2_033第5条）
  3. 反驳路径：出借人/收礼方主张已给付部分属自愿履行（注意2020修正后T2_011已删除旧"超四倍已付利息可请求返还"条款，返还依据转向第985条＋超出部分抵充本息的清算）
- 法律效果：超限利息部分不予支持，已付的可主张抵充本金或依不当得利返还；彩礼按共同生活及孕育情况、双方过错、当地习俗确定返还比例；借婚姻索取财物全额返还（T2_033第2条）
- 关键司法解释：民间借贷规定（T2_011）第25条（四倍LPR上限）、第28条（逾期利率上限）、第29条（逾期利息与违约金合计封顶）、第31条（2020年8月20日前后利率标准分段）；涉彩礼规定（T2_033）第3-6条；婚姻家庭编解释（一）（T1_003）第5条
- 常见抗辩与反击：给付彩礼方请求按不当得利全额返还 → 应适用彩礼专门规则按比例返还，案由为12.婚约财产纠纷而非不当得利；收礼方以"已用于共同生活"抗辩 → 扣除实际共同消费部分（T2_033第5条"彩礼实际使用及嫁妆情况"）
- 期间与时效：3年（第188条），自知道权利受损及对方之日起算；T2_033第7条规定其施行前已终审再审案件不适用
- 案由对应：148.不当得利纠纷（兜底）；12.婚约财产纠纷（彩礼优先）；民间借贷纠纷
- 检索口令：高利放贷＋LPR四倍＋已付利息返还＋彩礼返还比例＋借婚姻索取财物＋竞合
- 语料疑点：2020年修正的民间借贷规定删除了旧第31条（超四倍已付利息返还之诉的明文依据），返还请求权基础回归第985条与抵充规则，实务须先核对新旧条文分段适用

## 争点：准合同请求权的诉讼时效起算
- 请求权基础/抗辩规范：民法典第188条第1款；起算特别规则——诉讼时效规定（T1_010）第6、7条
- 构成要件树：
  1. 不当得利：知道或应当知道不当得利事实及对方当事人之日（T1_010第6条）
  2. 管理人费用偿还/损失赔偿请求权：无因管理行为结束并且管理人知道或应当知道本人之日（T1_010第7条第1款）
  3. 本人对不当管理的赔偿请求权：知道或应当知道管理人及损害事实之日（T1_010第7条第2款）
- 法律效果：3年期间届满义务人取得抗辩权（第192条）
- 关键司法解释：T1_010第6、7条；总则编解释（T1_004）第35条（20年最长期间不适用中止中断）
- 常见抗辩与反击：义务人以"应知"提前起算 → 原告举证此前客观上无法知悉对方身份（如错汇款项查无收款人）
- 期间与时效：3年；自权利受到损害之日起超过20年的不予保护（第188条第2款）
- 案由对应：148.不当得利纠纷；149.无因管理纠纷
- 检索口令：不当得利时效＋无因管理时效＋起算点＋诉讼时效规定第6条第7条

## 争点：无因管理之债是否成立（本人意思的审查）
- 请求权基础/抗辩规范：民法典第979条第1款（必要费用偿还请求权＋损失适当补偿请求权）
- 构成要件树：
  1. 管理人没有法定或约定义务 —— 原告举证义务不存在（消极事实，可先证明管理事实，由本人举证有义务）
  2. 有为避免他人利益受损的管理意思 —— 主观要件，误管他人事务不成立
  3. 管理了他人事务且本人受益
  4. 第979条第2款：管理事务不符合受益人真实意思的，不享有前款权利；但受益人真实意思违反法律或违背公序良俗的除外
- 法律效果：本人偿还因管理支出的必要费用（含利息），管理人因管理受损的适当补偿
- 关键司法解释：总则编解释（T1_004）第34条（见义勇为受损，依第183条请求受益人补偿的数额考量：损失与已获赔偿、受益多少、经济条件）
- 常见抗辩与反击：本人以"我明确不想让你管"抗辩 → 审查其真实意思是否违法或违俗（如拒绝救治自杀者）；费用合理性由本人举证过高
- 期间与时效：管理结束并知道本人之日起3年（T1_010第7条）
- 案由对应：149.无因管理纠纷（2025年案由规定"十二、无因管理纠纷"）
- 检索口令：无因管理＋必要费用＋本人真实意思＋公序良俗除外＋979

## 争点：紧急管理、不真正无因管理与见义勇为补偿的适用
- 请求权基础/抗辩规范：民法典第980条（管理不属于第979条但受益人享有管理利益的，在所得利益范围内承担第979条第1款义务）；第183条（保护他人权益受损，受益人适当补偿）；第184条（自愿紧急救助造成受助人损害，救助人不担责）
- 构成要件树：
  1. 误信管理（误他人事务为自己事务）或不法管理不成立第979条 → 转入第980条"利益范围内"返还
  2. 紧急救助免责三要件：自愿实施、紧急救助行为、造成受助人损害（第184条，无反向追偿设计）
- 法律效果：第980条限定在受益范围内承担费用偿还义务；第183条无侵权人或侵权人无力时受益人应当补偿
- 关键司法解释：总则编解释（T1_004）第34条（第183条补偿数额因素）
- 常见抗辩与反击：本人以"未经我同意"拒绝补偿 → 第980条不以本人意思为要件，仅需证明实际受益
- 期间与时效：T1_010第7条
- 案由对应：149.无因管理纠纷；183、184相关可用"见义勇为相关纠纷"案由
- 检索口令：980条＋利益范围内＋紧急救助＋见义勇为本条补偿＋183 184

## 争点：管理人方法、通知报告义务与追认后委托合同参照
- 请求权基础/抗辩规范：民法典第981条（有利方法、不得随意中断）、第982条（及时通知、等待指示）、第983条（报告与财产转交）、第984条（本人追认的自管理开始时适用委托合同规定，管理人另有意思表示除外）
- 构成要件树：
  1. 中断管理对本人不利且无正当理由 —— 本人举证
  2. 财产转交义务违反 → 本人可请求交付
  3. 追认的意思表示到达管理人 —— 管理人主张委托合同效果时举证
- 法律效果：管理人违反方法致损的可减其费用偿还并可能构成侵权；追认后按委托合同处理报酬与费用（第921、928条参照）
- 关键司法解释：无直接对应司法解释（准合同无专门解释；委托合同争议适用合同编通则解释）
- 常见抗辩与反击：管理人以"已尽力"抗辩中断责任 → 举证中断时本人已可自行管理
- 期间与时效：T1_010第7条
- 案由对应：149.无因管理纠纷
- 检索口令：无因管理＋管理人义务＋中断不利＋事后追认＋委托合同参照＋984

## 争点：人格权请求权（停止侵害/排除妨碍/消除危险/消除影响/恢复名誉/赔礼道歉）及其诉讼时效豁免
- 请求权基础/抗辩规范：民法典第995条（人格权请求权＋第2款六类请求权不适用诉讼时效）；第196条第1项（排除妨碍、消除危险等不适用时效的一般规范）
- 构成要件树：
  1. 人格权（第990条）受侵害、妨碍或有妨碍之虞 —— 原告证明侵害行为与权益归属
  2. 责任方式与侵害形态匹配：持续侵害→停止侵害；影响扩散→消除影响、恢复名誉；道德非难→赔礼道歉
  3. 抗辩路径：行为人主张第999条（公共利益合理使用）或第1020条（肖像合理使用）等违法阻却事由
- 法律效果：不以过错为要件（防御性请求权）；消除影响、恢复名誉、赔礼道歉应与行为方式和影响范围相当（第1000条第1款）；拒不履行的法院可在媒体刊登公告或生效裁判文书，费用由行为人负担（第1000条第2款）
- 关键司法解释：精神损害赔偿解释（T2_036）第1条（受理）、第5条（数额因素）；名誉权案件适用问题的相关解释按网络侵权规定（T2_005）衔接
- 常见抗辩与反击：行为人以"已过3年"抗辩停止侵害等请求权 → 第995条第2款明文排除时效适用；损害赔偿请求权仍受3年限制，须区分两类请求权
- 期间与时效：防御性请求权不适用时效；赔偿损失适用第188条
- 案由对应：第一部分"一、人格权纠纷"（1-11，如6.名誉权纠纷、8.隐私权、个人信息保护纠纷）
- 检索口令：995条＋人格权请求权＋不适用诉讼时效＋消除影响恢复名誉＋1000条＋登报执行

## 争点：人格权侵害禁令的申请要件与程序衔接
- 请求权基础/抗辩规范：民法典第997条（责令停止有关行为）；程序依《民事诉讼法》第103、104条行为保全（法〔2025〕226号修改后案由规定将其列为非讼程序案件案由）
- 构成要件树：
  1. 有证据证明正在实施或即将实施侵害人格权的违法行为 —— 申请人初步证明
  2. 不及时制止将使合法权益受到难以弥补的损害 —— 紧迫性
  3. 向人民法院申请（诉前或诉中均可）
- 法律效果：责令停止有关行为；可参照行为保全裁定、复议与解除程序
- 关键司法解释：婚姻家庭编解释（二）（法释〔2025〕1号）第12条——抢夺、藏匿未成年子女可申请人身安全保护令或参照第997条申请禁令；人脸识别规定（法释〔2021〕15号）第9条——对使用人脸识别技术的紧迫侵害法院可作出"人格权侵害禁令"；人身安全保护令规定（法释〔2022〕17号）第1条（不以提起离婚等诉讼为条件）及保护令程序批复（法释〔2016〕15号）第3项（不收费、不担保、比照特别程序）；知识产权行为保全规定（法释〔2018〕21号）第6、7、10、11条关于"情况紧急""难以弥补的损害"与担保的考量因素可参照
- 常见抗辩与反击：被申请人以"申请人已另行起诉"抗辩 → 禁令独立于本案诉讼（参照T2_028第1条第2款"不以提起民事诉讼为条件"）
- 期间与时效：不适用诉讼时效（第995条第2款）；保全裁定送达后立即执行，诉前保全后30日内起诉（T3_005第17条类推）
- 案由对应：非讼程序案件案由"五十二、申请人格权侵害禁令案件"（482.申请人格权侵害禁令）；关联案由"五十一、申请人身安全保护令案件"（481）
- 检索口令：997条＋人格权侵害禁令＋行为保全＋难以弥补的损害＋482号案由＋抢夺藏匿子女禁令

## 争点：人格权侵权责任、违约责任与精神损害赔偿的选择与并行
- 请求权基础/抗辩规范：民法典第996条（违约损害人格权造成严重精神损害的，主张违约责任不碍精神损害赔偿）、第186条（违约与侵权择一）、第1183条（精神损害赔偿）
- 构成要件树：
  1. 一方违约行为＋损害对方人格权＋严重精神损害 —— 受害人举证后果严重性
  2. 责任方式相当性（第1000条第1款）
  3. 认定责任考量因素：行为人与受害人职业、影响范围、过错程度、行为目的方式后果（第998条，生命身体健康权除外）
- 法律效果：违约之诉中可并列精神损害赔偿（突破旧规则）；另依第187条民事责任优先于行政、刑事责任受偿
- 关键司法解释：精神损害赔偿解释（T2_036）第1条（受理范围：人身权益或具有人身意义的特定物）、第4条（法人、非法人组织无精神损害赔偿）、第5条（数额六因素）；人身损害赔偿解释（T2_029）衔接残疾赔偿金等物质项目
- 常见抗辩与反击：违约方援引"违约之诉不支持精神赔偿"旧抗辩 → 第996条已明文改变；未达"严重"标准 → 法院驳回精神赔偿但可支持其他责任方式
- 期间与时效：损害赔偿请求权适用3年（第188条）
- 案由对应：按被侵害权利定一级人格权案由（如服务合同违约涉人格权：同时列合同纠纷与人格权纠纷案由由法院择定）
- 检索口令：996条＋违约精神损害赔偿＋严重精神损害＋1183＋精神损害赔偿解释第5条

## 争点：死者人格利益侵害的请求权主体与责任
- 请求权基础/抗辩规范：民法典第994条（死者姓名、肖像、名誉、荣誉、隐私、遗体受侵害的近亲属请求权）；第185条（侵害英雄烈士姓名、肖像、名誉、荣誉损害公共利益的民事责任）
- 构成要件树：
  1. 死者人格利益受损 —— 原告举证侵权行为
  2. 原告适格：配偶、子女、父母为第一顺位；无配偶子女且父母已亡的其他近亲属（第994条第2句）
  3. 抗辩：行为人主张公共利益、学术研究、新闻报道合理使用（第999条）
- 法律效果：停止侵害、消除影响、恢复名誉、赔礼道歉＋精神损害赔偿（近亲属自身精神利益）
- 关键司法解释：精神损害赔偿解释（T2_036）第3条——死者人格利益受侵害近亲属诉请精神损害赔偿的应予支持
- 常见抗辩与反击：被告以"死者无权利能力"抗辩 → 保护的是近亲属人格利益与死者人格法益；烈士案件检察机关可提起公益诉讼
- 期间与时效：防御性请求不适用时效；赔偿适用3年
- 案由对应：一、人格权纠纷项下相应权利案由＋"英雄烈士保护民事公益诉讼"案由（公益诉讼部分）
- 检索口令：994条＋死者人格利益＋近亲属请求权＋185条英烈＋遗体

## 争点：人格要素许可使用与姓名权、名称权侵害认定
- 请求权基础/抗辩规范：民法典第990条（具体人格权＋一般人格权）、第992条（人格权不得放弃、转让、继承）、第993条（姓名、名称、肖像可许可使用）、第1014条（禁止干涉、盗用、假冒他人姓名/名称）；请求权在第1012、1013条
- 构成要件树：
  1. 姓名权：干涉、盗用、假冒行为 + 特定同一性 —— 受害人举证身份指向
  2. 姓氏选取：原则随父姓或母姓，第1015条三项例外（直系长辈血亲姓、扶养人姓、不违俗正当理由）—— 登记机关拒登纠纷
  3. 笔名、艺名、网名、译名、字号、姓名名称简称：有一定社会知名度＋使用足以造成公众混淆（第1017条参照保护）
  4. 登记与效力：变更姓名/名称登记，变更前行为仍约束（第1016条）
- 法律效果：停止侵害、赔礼道歉、赔偿损失（参照第995、998、1000条）
- 关键司法解释：总则编解释（T1_004）第3条（第132条滥用权利规制，可对"注册他人姓名抢注"类行为不予保护评价）；反不正当竞争领域的字号仿冒适用相应知产解释（另册）
- 常见抗辩与反击：使用人以"重名巧合"抗辩 → 审查知名度与混淆可能性（第1017条）
- 期间与时效：防御性请求权不适用时效（第995条第2款）
- 案由对应：2.姓名权纠纷；3.名称权纠纷
- 检索口令：姓名权＋盗用假冒＋1015条＋选取姓氏＋笔名艺名网名＋1017条＋许可使用993

## 争点：肖像权侵害认定与合理使用（第1020条）的边界
- 请求权基础/抗辩规范：民法典第1018条（肖像定义：可识别的外部形象）、第1019条（禁止丑化污损、信息技术伪造；未经同意不得制作使用公开；未经同意肖像作品权利人不得发表复制发行出租展览）；抗辩：第1020条五项合理使用
- 构成要件树：
  1. "可识别性"—— 是否指向特定自然人（漫画、剪影、侧影、AI换脸均看可识别）—— 原告举证
  2. 未经同意制作、使用、公开 —— 不以营利为要件（旧民法通则营利要件已废弃）
  3. 合理使用抗辩：个人学习欣赏教学科研必要范围内使用已公开肖像；新闻报道不可避免；国家机关履职必要范围；展示公共环境不可避免；维护公共利益或肖像权人合法权益
- 法律效果：停止侵害、消除影响、赔礼道歉、赔偿损失（按第1182条侵害人身权益财产损失计算，或精神损害赔偿）
- 关键司法解释：网络侵权规定（T2_005）第12条（制止侵权合理开支含律师费计入财产损失）；利用信息技术伪造（深度合成）另受互联网信息服务深度合成管理规定等公法规制
- 常见抗辩与反击：使用人主张"已注明出处"→ 不构成免责；主张"公共场所拍摄"→ 须属第1020条第4项"不可避免展示特定公共环境"，特写仍侵权
- 期间与时效：同995条规则
- 案由对应：4.肖像权纠纷；5.声音保护纠纷
- 检索口令：肖像权＋可识别性＋营利要件废除＋1020条＋合理使用＋AI换脸＋丑化污损

## 争点：肖像、姓名许可使用合同的解释、解除与争议处理
- 请求权基础/抗辩规范：民法典第1021条（使用条款理解争议作有利于肖像权人的解释）、第1022条（期限无约定或不明：双方随时解除＋合理期限前通知；有明确约定：肖像权人有正当理由可解除，造成损失的非不可归责事由应赔偿）、第1023条（姓名等许可参照肖像许可；声音保护参照肖像权）
- 构成要件树：
  1. 许可合同成立生效（第993条允许许可，但法定或性质不可许可除外）
  2. 使用范围争议 → 有利肖像权人解释（第1021条）
  3. 解除权：区分约定期限有无，"正当理由"审查
- 法律效果：解除后继续使用的构成侵权；解除造成损失赔偿
- 关键司法解释：无直接对应司法解释；合同争议可适用合同编通则解释（T1_002）关于合同解释（第1条以下）与解除（第24条违约方起诉解除）的规定
- 常见抗辩与反击：使用人以"合同约定永久授权"抗辩 → 参照第1022条第1款期限不明随时解除规则与人格权不可转让性（第992条）限缩
- 期间与时效：合同请求权3年
- 案由对应：肖像权纠纷（或合同纠纷，按诉争法律关系性质定）
- 检索口令：肖像许可合同＋1021条＋有利于肖像权人解释＋随时解除＋声音参照＋1023

## 争点：舆论监督、新闻报道侵害名誉权的免责与例外
- 请求权基础/抗辩规范：民法典第1024条（名誉权，侮辱诽谤禁止）、第1025条（舆论监督免责＋三项除外：捏造歪曲事实；严重失实内容未尽合理核实义务；使用侮辱性言辞贬损）、第1026条（核实义务六因素）；第999条（公共利益合理使用）
- 构成要件树：
  1. 指向特定人的贬损性内容＋社会评价降低 —— 原告
  2. "事实基本真实"抗辩：报道核心事实真实，细节失实不侵权（第1025条反面）
  3. 核实义务判断：内容来源可信度、是否必要调查、时限性、与公序良俗关联性、受害人名誉贬损可能性、核实能力与成本（第1026条）
  4. 侮辱性言辞独立构成侵权（即使事实属实）
- 法律效果：消除影响、恢复名誉、赔礼道歉、赔偿损失（第995、1000条）
- 关键司法解释：网络侵权规定（T2_005）第7条（转载行为过错程度认定）；精神损害赔偿解释（T2_036）第4条（法人无精神损害赔偿）
- 常见抗辩与反击：媒体以"消息来自官方通报"→ 属第1026条第1项来源可信度高的抗辩；原告以"我未被打扰报道即侵权"→ 需证明特定指向与社会评价降低
- 期间与时效：删除、停止传播等防御请求不适用时效（第995条第2款）；赔偿3年
- 案由对应：6.名誉权纠纷
- 检索口令：舆论监督＋基本属实＋合理核实义务＋1025 1026＋侮辱性言辞＋转载过错

## 争点：报道失实更正删除请求权与信用信息处理规则
- 请求权基础/抗辩规范：民法典第1028条（有证据证明媒体报道失实→请求媒体及时更正、删除等必要措施）、第1029条（信用评价异议更正）、第1030条（与征信机构等信用信息处理者关系适用个人信息保护规定）
- 构成要件树：
  1. 报道/信息内容失实 —— 权利人初步证明
  2. 请求对象为刊播该内容的媒体/信用信息处理者
  3. 媒体未及时采取措施 → 可诉请强制更正删除＋侵害扩大部分责任
- 法律效果：更正、删除、断开链接等必要措施；拒不执行的按第1000条第2款处理
- 关键司法解释：网络侵权规定（T2_005）第4条（必要措施及时性判断：服务类型、通知形式准确度、侵害类型程度）、第5条（收到有效通知采取措施的网络服务者对断开链接免责抗辩成立）、第10条（有偿删帖协议无效；擅自删帖构成侵权）
- 常见抗辩与反击：媒体以"内容系用户提供"抗辩 → 收到有效通知后仍须及时措施（民法典第1195条衔接）；"有偿删帖"合同不受保护（T2_005第10条）
- 期间与时效：更正删除请求不适用时效（第995条第2款）
- 案由对应：6.名誉权纠纷；（2）个人信息保护纠纷
- 检索口令：1028条＋更正删除权＋信用评价异议＋有偿删帖无效＋网络侵权规定第4条第10条

## 争点：隐私权侵害（私人生活安宁与私密信息）的认定
- 请求权基础/抗辩规范：民法典第1032条（隐私定义：私人生活安宁＋私密空间、私密活动、私密信息）、第1033条（六类禁止行为：电话短信等侵扰安宁；进入拍摄窥视住宅宾馆等私密空间；拍摄窥视窃听公开私密活动；拍摄窥视身体私密部位；处理私密信息；其他）
- 构成要件树：
  1. 客体属隐私——"私密性＋不愿为他人知晓"—— 原告举证
  2. 行为落入第1033条列举
  3. 抗辩：法律另有规定或权利人明确同意（第1033条前言）
- 法律效果：停止侵害、消除影响、赔礼道歉、赔偿损失＋精神损害赔偿（第1183条；T2_036第1条）
- 关键司法解释：精神损害赔偿解释（T2_036）第1条；离婚损害赔偿中私密行为取证须以合法方式（偷拍他人隐私的证据不具合法性，衔接证据规则）
- 常见抗辩与反击：取证方以"对方配偶出轨涉我知情权"抗辩 → 在自家安装监控取证的合法性与侵入他人私密空间区分认定
- 期间与时效：防御请求不适用时效；赔偿3年

- 构成要件树：
  1. 债权人主张共债：金额与用途是否超出家庭日常生活需要 —— 超出时举证责任转由债权人承担（用于共同生活/共同经营/共同意思）

  3. 财产约定对抗：配偶一方举证相对人知道约定（第1065条第3款，举证责任在主张对抗方——T1_003第37条）
- 法律效果：共同债务以共同财产及各自个人财产连带清偿；离婚协议或判决对债务的分担不得对抗债权人（T1_003第35条），一方清偿后可按协议/文书向另一方追偿

- 期间与时效：主债务时效3年（第188条）；债权人对离婚协议财产条款的撤销权受第152、541条除斥期间限制

- 检索口令：1064条＋共债共签＋家庭日常生活需要＋举证责任＋1060条＋离婚协议逃避债务撤销

## 争点：婚姻关系存续期间共同财产分割与挥霍、恶意赠与的规制

- 构成要件树：
  1. 法定情形之一 —— 请求方举证
  2. 2025年细化：未经另一方同意网络直播打赏明显超出家庭一般消费水平且严重损害共同财产利益的，认定"挥霍"（T1_006第6条）；为重婚、同居等违反忠实义务目的将共同财产赠与他人或以明显不合理低价处分 → 违背公序良俗无效＋按第157条处理＋可依第1066/1092条请求分割或少分不分（T1_006第7条）

- 关键司法解释：婚姻家庭编解释（一）（T1_003）第38条（除第1066条情形外婚内分割请求不受理）；婚姻家庭编解释（二）（法释〔2025〕1号）第6条、第7条
- 常见抗辩与反击：打赏方以"消费已完成"抗辩 → 无效民事法律行为自始无约束力（第155条），可主张返还；配偶仅笼统主张"乱花钱" → 未达"严重损害"不予分割
- 期间与时效：婚内分割不适用时效（通说，身份关系存续）；离婚后发现隐匿财产再次分割自发现之日起3年（T1_003第84条）

- 检索口令：1066条＋婚内分割＋直播打赏挥霍＋打赏返还＋赠小三无效＋1092少分不分＋法释〔2025〕1号第6条第7条

## 争点：协议离婚程序、离婚冷静期与虚假离婚、离婚协议债权人撤销

  4. 财产及债务处理协议以协议离婚为条件，离婚未成一方反悔：协议不生效（T1_003第69条第1款）

- 关键司法解释：婚姻家庭编解释（一）（T1_003）第69、70条（登记离婚后就财产分割反悔，无欺诈胁迫则驳回）；婚姻家庭编解释（二）（法释〔2025〕1号）第2、3条
- 常见抗辩与反击：债务人以"抚养费义务对价"抗辩撤销 → 法院综合子女抚养费负担裁量（T1_006第3条）；一方以"假离婚应恢复" → 身份效力不可逆，只能复婚登记（第1083条）
- 期间与时效：债权人撤销权除斥期间：知道撤销事由1年、行为发生5年（第541条）；财产分割协议反悔之诉在离婚后提出，时效适用第188条

- 检索口令：1077条＋离婚冷静期＋两个三十日＋虚假离婚＋离婚协议财产条款撤销＋法释〔2025〕1号第3条

## 争点：诉讼离婚判准/判不离的标准与"判不准离婚后分居满一年"再诉
- 请求权基础/抗辩规范：民法典第1079条（感情破裂调解无效应准离：重婚或与他人同居；家暴虐待遗弃；赌博吸毒恶习屡教不改；因感情不和分居满2年；其他情形；一方被宣告失踪应准离；判不准离婚后又分居满1年一方再诉应准离）；第1081条（军婚）、第1082条（孕期分娩终止妊娠限制男方起诉）
- 构成要件树：
  1. 法定情形举证：分居满2年需因感情不和且连续（证人、租房、社区证明）；"与他人同居"=有配偶者与婚外异性不以夫妻名义持续稳定共同居住（T1_003第2条）
  2. 判不准离婚后：分居起算点为判决生效之日，满1年后再次起诉（第1079条第5款），"应当准予离婚"为羁束性规定
  3. 特殊限制：军人一方无重大过错时非军人方诉离须征得其同意（第1081条；"重大过错"依第1079条第3款前三项等判断——T1_003第64条）；女方怀孕、分娩后1年内、终止妊娠后6个月内男方不得起诉（第1082条，女方提出或法院确有必要受理除外）
  4. 调解前置：法院审理离婚案件应当调解（第1079条第2款）
- 法律效果：准予/不准离婚判决；离婚判决、调解书生效即解除婚姻关系（第1080条）
- 关键司法解释：婚姻家庭编解释（一）（T1_003）第1条（持续经常性家暴认定虐待）、第2条、第23条（生育权纠纷按其他破裂情形处理）、第62条（无配偶方代理无民事行为能力人离婚诉讼）、第63条（符合应准离情形不因对方无过错而判不离）、第64条；人身安全保护令规定（T2_028）第11条（判不离后违反保护令实施家暴构成再诉"新情况、新理由"）
- 常见抗辩与反击：被告以"仍有感情"抗辩 → 对照五项法定情形证据；原告分居证据仅有自述 → 补强共同居住反证排除
- 期间与时效：不适用诉讼时效；判不准离婚后再诉受民诉法"6个月内无新情况不受理"限制，分居满1年即满足再诉实体条件
- 案由对应：14.离婚纠纷；婚姻无效纠纷（17）、撤销婚姻纠纷（18）另列
- 检索口令：1079条＋感情破裂＋分居满二年＋判不离后分居满一年＋1081军婚＋1082＋新情况新理由

## 争点：离婚损害赔偿（含婚姻无效被撤销的损害赔偿）
- 请求权基础/抗辩规范：民法典第1091条（重婚；与他人同居；家暴；虐待遗弃家庭成员；其他重大过错致离婚——无过错方损害赔偿请求权）；第1054条第2款（婚姻无效或被撤销，无过错方请求损害赔偿）
- 构成要件树：
  1. 离婚事实＋法定过错事由 —— 无过错方举证过错与因果
  2. "其他重大过错"兜底：类推前三项严重性（长期通奸生育子女、嫖娼等）
  3. 主体与时序：承担主体为无过错方的配偶（T1_003第87条第1款）；不判决离婚则不支持（第87条第2款）；婚内不诉离单独请求不受理（第87条第3款）；原告须同时提出，被告不同意离婚亦未提出的可单独起诉（第88条）；登记离婚后提出应受理，但协议离婚时明示放弃除外（第89条）
  4. 双方均有过错：互相请求不予支持（第90条）
- 法律效果：物质损害赔偿＋精神损害赔偿（T1_003第86条援引T2_036）
- 关键司法解释：婚姻家庭编解释（一）（T1_003）第86、87、88、89、90条；精神损害赔偿解释（T2_036）第5条（数额因素）
- 常见抗辩与反击：被请求方以"协议离婚已财产让步"抗辩 → 除非明示放弃，赔偿请求权不消灭；"出轨证据系偷捉"→ 证据合法性审查（严重侵害他人隐私的取证无效）
- 期间与时效：随离婚诉讼或在其后一年内单独提出（T1_003第88条时序规则）；赔偿请求适用3年时效自离婚生效或知悉过错时起算
- 案由对应：16.离婚后损害责任纠纷（含1054条无过错方损害赔偿）；14.离婚纠纷并案
- 检索口令：1091条＋重大过错＋离婚损害赔偿＋精神损害＋88条时序＋双方有过错

## 争点：离婚共同财产分割、家务劳动补偿、经济帮助与隐藏财产再分割

- 常见抗辩与反击：主张补偿方以"全职照顾家庭"笼统主张 → 举证抚育、照料老人、协助工作的持续性；隐匿方以"用于正常开支"抗辩 → 资金流向审计＋T1_006第6条打赏类推审查
- 期间与时效：离婚时未分割财产可起诉再分割（T1_003第83条）；第1092条再分割时效3年自发现之日起算（T1_003第84条）
- 案由对应：15.离婚后财产纠纷；28.分家析产纠纷
- 检索口令：1087条＋照顾无过错方＋家务补偿1088＋父母出资购房＋法释〔2025〕1号第5条第8条＋1092再次分割＋共同还贷补偿

## 争点：同居关系析产与非婚生子女权利
- 请求权基础/抗辩规范：民法典第1054条（无效/被撤销婚姻同居期间财产协议→照顾无过错方判决；重婚无效财产不得侵害合法婚姻当事人权益）、第1071条（非婚生子女同等权利，不直接抚养方负担抚养费）
- 构成要件树：
  1. 受理边界：仅请求解除同居关系不予受理；涉财产分割或子女抚养的应受理（T1_003第3条）
  2. 双方均无配偶的同居析产：有约定按约定；无约定各自所得归各自；共同购置、共同生产经营收益及无法区分财产按出资比例为基础，综合共同生活情况、有无共同子女、贡献大小分割（T1_006第4条）
  3. 事实婚姻：1994年2月1日《婚姻登记管理条例》实施前已符合实质要件的按事实婚姻处理（T1_003第7条），继承按配偶主张亦同（第8条）
  4. 被确认无效或被撤销婚姻同居财产：除有证据证明归一方外按共同共有处理（T1_003第22条）
- 法律效果：一般共有规则分割（不适用夫妻共同财产推定）；子女抚养按第1084条
- 关键司法解释：婚姻家庭编解释（一）（T1_003）第3、7、8、22条；婚姻家庭编解释（二）（法释〔2025〕1号）第4条
- 常见抗辩与反击：一方主张同居财产均分 → 无配偶同居不适用共同共有推定，须证明共同出资/共同经营；"彩礼已转化为共同生活消费"抗辩 → 与T2_033第5、6条扣减衔接
- 期间与时效：析产、抚养费请求适用3年
- 案由对应：20.同居关系纠纷之（1）同居关系析产纠纷、（2）同居关系子女抚养纠纷
- 检索口令：同居析产＋法释〔2025〕1号第4条＋事实婚姻94年2月1日＋非婚生子女1071＋共同共有推定

## 争点：子女直接抚养归属、抚养费给付与变更
- 请求权基础/抗辩规范：民法典第1067条（抚养费给付请求权：未成年子女或不能独立生活的成年子女）、第1084条（不满2周岁随母原则；已满2周岁最有利于未成年子女原则；已满8周岁尊重真实意愿）、第1085条（协议/判决不碍子女必要时超额请求）、第1086条（探望权及中止）
- 构成要件树：
  1. "不能独立生活的成年子女"：尚在校接受高中及以下学历教育，或丧失、部分丧失劳动能力等非因主观原因无法维持正常生活（T1_003第41条）
  2. 抚养费范围：生活费、教育费、医疗费（T1_003第42条）；数额：有固定收入按月总收入20%-30%，负担两个以上子女不超50%；无固定收入参照当年总收入或同行业平均收入（T1_003第49条）；定期给付为原则（第50条）、无收入或下落不明以财物折抵（第51条）、至18周岁止（第53条）
  3. 抚养关系变更：与子女共同生活方患重病伤残无力继续抚养、不尽义务或虐待、8周岁以上子女愿随他方且他方有能力、其他正当理由（T1_003第56条）
  4. 增加抚养费：原定数额不足维持当地生活水平、患病上学实际需要超过原定、其他正当理由（T1_003第58条）
  5. 2025年新规：离婚协议约定一方不负担抚养费，后直接抚养方经济状况显著恶化或子女必要费用显著增加→子女仍可请求支付（T1_006第16条）；承诺抚养费欠付，成年独立后直接抚养方追索欠付费用应予支持（T1_006第17条）
  6. 探望：离婚判决未涉探望可单独起诉（第65条）；中止探望请求权人含子女本人、直接抚养方等（第67条）；不得对子女人身强制执行（第68条）
- 法律效果：判决定期给付；变更另诉（第55条）
- 关键司法解释：婚姻家庭编解释（一）（T1_003）第41-61、65-68条；婚姻家庭编解释（二）（法释〔2025〕1号）第16、17条
- 常见抗辩与反击：支付方以"对方再婚/收入提高"要求减免 → 子女权利不受父母身份变动影响，仅"原定数额足以维持且情势变更"时酌减；以"子女改姓"拒付 → 明确禁止（T1_003第59条）
- 期间与时效：抚养费给付请求不适用诉讼时效（第196条第3项）；欠付抚养费的追索同样不受时效限制（通说），但财产性补偿请求注意区分
- 案由对应：22.抚养纠纷之（1）抚养费纠纷、（2）变更抚养关系纠纷；27.探望权纠纷
- 检索口令：1084条＋最有利于未成年子女＋抚养费比例20%30%＋变更抚养＋法释〔2025〕1号第16条17条＋196条不适用时效

## 争点：抢夺、藏匿未成年子女的禁令、责任与抚养评价
- 请求权基础/抗辩规范：婚姻家庭编解释（二）（法释〔2025〕1号）第12条（申请人身安全保护令或参照民法典第997条申请人格权侵害禁令）；第13条（分居期间抢夺藏匿致无法履行监护职责：参照第1084条暂定抚养事宜＋明确暂时直接抚养方协助义务）；第14条（抚养归属优先考虑由另一方直接抚养的五情形，含抢夺藏匿）
- 构成要件树：
  1. 抢夺、藏匿行为——使另一方无法探望、抚养、监护 —— 申请方举证（报警记录、聊天记录）
  2. 被申请人抗辩"对方存在赌博吸毒家暴等严重侵害子女情形"→ 法院应告知其通过撤销监护资格、中止探望、变更抚养关系解决；未举证且未在合理期限提出相关请求的，仍支持禁令（T1_006第12条第2款）
  3. 精神损害：非法使被监护人脱离监护致亲子关系严重损害——近亲属可诉精神损害赔偿
- 法律效果：责令送回、禁止藏匿、暂时确定抚养安排；违反保护令可依刑法拒不执行判决裁定罪追责（T2_028第12条）
- 关键司法解释：婚姻家庭编解释（二）（法释〔2025〕1号）第12-14条；人身安全保护令规定（T2_028）第1、6条（较大可能性证明标准＋证据清单）；精神损害赔偿解释（T2_036）第2条（非法使被监护人脱离监护受理）；侵权责任编解释（一）（法释〔2024〕12号）第2条（认定第1183条第1款"严重精神损害"）
- 常见抗辩与反击：抢夺方以"我是父/母有监护权"抗辩 → 监护平等＋最有利于子女原则，藏匿本身即为不利评价因素（T1_006第14条第4项）
- 期间与时效：不适用诉讼时效（第995条第2款防御请求）；抚养权诉讼中作为情节主张
- 案由对应：482.申请人格权侵害禁令；481.申请人身安全保护令；22.抚养纠纷
- 检索口令：抢夺藏匿未成年子女＋法释〔2025〕1号第12条＋人格权侵害禁令＋暂时抚养＋精神损害脱离监护

## 争点：收养关系成立、效力、无效与解除
- 请求权基础/抗辩规范：民法典第1104条（双方自愿，收养8周岁以上应征得本人同意）、第1105条（登记成立＋收养评估）、第1111条（拟制血亲效力；与生父母权利义务消除）、第1113条（违反第一编无效规定或本编规定的收养无效）、第1114-1118条（解除及后果）
- 构成要件树：
  1. 收养人条件：无子女或只有一名子女、抚养教育保护能力、无医学上不应收养疾病、无违法犯罪记录、年满30（第1098条）；无配偶者收养异性子女年龄差40以上（第1102条）；继子女收养放宽（第1103条）
  2. 登记生效：自登记之日起成立（第1105条第1款）；未登记仅公证、协议不成立收养关系
  3. 解除：未成年时被收养人原则不得解除，收养人送养人协议解除或送养人诉请解除（收养人不履行抚养义务、虐待遗弃——第1114条）；养父母与成年养子女关系恶化可协议或诉讼解除（第1115条）；协议解除应到民政部门登记（第1116条）
  4. 解除后果：与养父母关系消除、与生父母关系自行恢复（成年养子女可协商——第1117条）；生活费给付与抚养费补偿（第1118条）
- 法律效果：无效收养自始无约束力；解除后涉继承资格变化（对照第1127条养子女定义）
- 关键司法解释：继承编解释（一）（T1_009）第10条（被收养人对生父母扶养较多可酌分遗产）、第12条（养兄弟姐妹互为第二顺序）；收养评估为部门规章层面要求（民法典第1105条第5款授权）
- 常见抗辩与反击：以"事实收养"（未登记长期共同生活）主张继承权 → 1992年《收养法》施行前形成的事实收养承认，施行后未登记原则不成立（衔接T1_001第1条时间效力）
- 期间与时效：确认收养无效不受时效限制；解除之诉无期间限制
- 案由对应：25.收养关系纠纷之（1）确认收养关系纠纷、（2）解除收养关系纠纷
- 检索口令：收养登记＋1105条＋1113无效＋解除收养＋养子女继承＋事实收养

## 争点：继承开始、遗嘱与遗赠扶养协议的适用顺序及共同死亡推定
- 请求权基础/抗辩规范：民法典第1121条（继承自被继承人死亡时开始；相互有继承关系之人同一事件死亡推定规则）、第1123条（法定继承→遗嘱继承/遗赠→遗赠扶养协议顺序）

  1. 死亡时点：生理死亡或宣告死亡（宣告死亡日期依第48条——T1_009第1条第2款）

- 常见抗辩与反击：以"死亡医学证明时间"争执推定顺序 → 第1121条第2款为法律推定，可举证实际死亡时间反证

## 争点：遗产范围界定与网络虚拟财产、特殊财产继承
- 请求权基础/抗辩规范：民法典第1122条（遗产＝自然人死亡时遗留的个人合法财产；依法律规定或性质不得继承的除外）、第127条（法律对数据、网络虚拟财产的保护有规定依其规定）
- 构成要件树：
  1. 个人合法财产性——先析出他人份额：夫妻共同财产先分一半给配偶（第1153条第1款）；家庭共有先析出他人财产（第1153条第2款）
  2. 可继承性：承包收益（承包人死亡时尚未取得收益的，投入资金与劳动增值孳息折价补偿为遗产——T1_009第2条）；人身专属权利义务（抚恤金请求权、指定受益人的人身保险金）不属遗产
  3. 网络虚拟财产/数据：账号、加密货币、店铺、游戏装备——依平台服务协议可转让性与人身属性审查；2025年案由规定新设"第六部分 数据、网络虚拟财产纠纷"（十八、网络虚拟财产纠纷）提供案由通道
  4. 宅基地使用权、公有住房承租权按专门规定处理（性质上非典型遗产，居住利益可承继与否个案审查）

- 常见抗辩与反击：以"账号有人身专属性不得继承"抗辩 → 区分财产价值部分（虚拟财产）与人格利益部分（通讯记录隐私）

- 检索口令：遗产范围＋1122条＋虚拟财产继承＋网络虚拟财产案由＋承包收益折价＋抚恤金非遗产

## 争点：法定继承顺序、代位继承、转继承与份额分配
- 请求权基础/抗辩规范：民法典第1127条（第一顺序：配偶子女父母；第二顺序：兄弟姐妹祖父母外祖父母；子女父母兄弟姐妹的拟制血亲范围）、第1128条（代位继承：子女先死→直系晚辈血亲；兄弟姐妹先死→其子女）、第1129条（丧偶儿媳女婿尽主要赡养义务为第一顺序）、第1130-1131条（份额与酌分）

  2. 代位继承要件：被代位人先于被继承人死亡＋被代位人未丧失继承权（T1_009第17条：继承人丧失继承权的其晚辈直系血亲不得代位，但代位人缺乏劳动能力又无生活来源或尽赡养义务较多可适当分给）；代位不受辈数限制（第14条）；拟制血亲代位链（第15条）
  3. 份额：均等原则＋四向调整（困难且缺劳力者照顾；尽主要扶养或共同生活者可多分；有能力不扶养者不分或少分；协商可不均等——第1130条）
  4. 继承人以外之人：依靠被继承人扶养者或扶养较多者酌分遗产（第1131条；T1_009第20条可多可少于继承人、第21条独立原告资格）

- 常见抗辩与反击：以"嫁出女不继承"习俗抗辩 → 第1126条男女平等、习俗不得违背公序良俗（T1_004第2条第3款）；主张丧偶儿媳第一顺序 → 举证"主要赡养"（主要经济来源或劳务扶助——T1_009第19条）
- 期间与时效：继承权纠纷3年；遗产分割请求不受时效（共有状态）
- 案由对应：29.法定继承纠纷之（1）转继承纠纷、（2）代位继承纠纷；34.非遗产继承人分配遗产纠纷
- 检索口令：代位继承＋1128条＋丧失继承权＋份额调整＋酌情分得遗产权＋丧偶儿媳1129

## 争点：遗嘱形式要件（含打印、录像遗嘱）、遗嘱能力与遗嘱无效
- 请求权基础/抗辩规范：民法典第1134-1139条（自书、代书、打印、录音录像、口头、公证六种形式及要件）、第1140条（见证人消极资格）、第1141条（必留份）、第1142条（撤回变更＋数份遗嘱以最后为准）、第1143条（遗嘱能力、真实意思、伪造篡改无效）
- 构成要件树：
  1. 打印遗嘱：两个以上见证人在场见证＋遗嘱人和见证人在每一页签名、注明年月日（第1136条）—— 缺任何一形式要件即无效
  2. 录音录像遗嘱：两个以上见证人在场＋遗嘱人和见证人在录音录像中记录姓名或肖像及年月日（第1137条）
  3. 口头遗嘱：危急情况＋两个以上见证人；危急情况消除后能以书面或录音录像所立之口头遗嘱无效（第1138条）
  4. 见证人：无/限制行为能力人、继承人受遗赠人、与其有利害关系者（其债权人、债务人、合伙人——T1_009第24条）不得见证
  5. 遗嘱能力以立遗嘱时为断（T1_009第28条）；伪造无效、篡改部分无效（第1143条第3、4款）
  6. 撤回：与遗嘱相反的民事法律行为视为撤回（第1142条第2款）；公证遗嘱不再优先，数份抵触以最后为准（第1142条第3款；T1_001第23条溯及衔接）
- 法律效果：无效部分遗产按法定继承（第1154条第4项）；处分他人财产部分无效（T1_009第26条）；遗书符合要件按自书遗嘱对待（T1_009第27条）
- 关键司法解释：继承编解释（一）（T1_009）第24、26、27、28条；总则编解释（T1_004）第5条（行为能力相适应判断参照）
- 常见抗辩与反击：主张遗嘱人"神志不清"→ 申请调取诊疗记录、公证卷宗（第1143条第1款举证责任在主张方）；见证人系受益人之婿 → 利害关系排除（第1140条第3项）
- 期间与时效：确认遗嘱无效之诉不受时效限制；继承权受侵害请求3年
- 案由对应：30.遗嘱继承纠纷
- 检索口令：打印遗嘱要件＋录音录像遗嘱＋每一页签名＋见证人利害关系＋最后遗嘱为准＋遗书按自书遗嘱

## 争点：必留份、附义务遗嘱与遗嘱信托
- 请求权基础/抗辩规范：民法典第1141条（应为缺乏劳动能力又没有生活来源的继承人保留必要遗产份额）、第1144条（附义务遗嘱/遗赠，无正当理由不履行可经请求取消接受附义务部分遗产权利）、第1133条第4款（遗嘱信托）
- 构成要件树：
  1. "双缺"继承人认定：以遗嘱生效时该继承人具体情况确定（T1_009第25条第2款）
  2. 未保留必留份的处理：先留出必要份额，剩余部分才参照遗嘱分配（T1_009第25条第1款）；分割遗产清偿债务时同样保留（第1159条）
  3. 附义务不履行：义务能够履行＋无正当理由不履行 → 受益人或其他继承人请求法院取消其接受附义务部分遗产的权利，由请求人按遗嘱人意愿履行义务接受遗产（T1_009第29条）
- 法律效果：部分无效遗嘱内容转法定继承；信托受托人义务按信托法处理
- 关键司法解释：继承编解释（一）（T1_009）第25、29条
- 常见抗辩与反击：遗嘱主张"我有劳动能力的亲属不配照顾"→ 双缺须同时具备；受遗赠人不履行赡养义务 → 第1144条取消路径而非整体无效
- 期间与时效：随继承诉讼主张；第1144条取消请求在遗产处理前提出为宜
- 案由对应：30.遗嘱继承纠纷；32.遗赠纠纷
- 检索口令：必留份＋缺乏劳动能力又无生活来源＋遗嘱生效时点＋附义务遗赠＋取消接受遗产权利＋遗嘱信托

## 争点：遗产管理人的产生、职责、责任与报酬
- 请求权基础/抗辩规范：民法典第1145条（管理人顺位：遗嘱执行人→继承人推选→继承人共同担任→民政部门或村委会）、第1146条（争议时利害关系人可申请法院指定）、第1147条（六项职责）、第1148条（故意或重大过失损害继承人、受遗赠人、债权人利益的民事责任）、第1149条（报酬依法律规定或约定）
- 构成要件树：
  1. 指定申请：对管理人确定有争议 → 利害关系人（含债权人）向法院申请
  2. 责任要件：违反第1147条职责＋故意/重大过失＋损害 —— 请求方举证
  3. 债权人对遗产的追及：管理人未清理通知致债权人受损
- 法律效果：管理人资格确认；损害赔偿；可诉请履行清理、报告、债务处理职责
- 关键司法解释：继承编解释（一）（T1_009）第44条（诉讼中继承人不参加又不放弃的追加共同原告）衔接当事人确定；指定遗产管理人案件适用特别程序（2025年案由规定"非讼程序案件案由"445.申请指定遗产管理人）
- 常见抗辩与反击：民政部门抗辩"无继承人之遗产无人管理"→ 第1145条明定其兜底任职；继承人以"未实际管理"免责 → 共同担任期间对消极行为亦可能构成重大过失
- 期间与时效：第1148条赔偿请求适用3年
- 案由对应：35.遗产管理纠纷之（1）遗产管理人责任纠纷、（2）遗产管理人报酬纠纷；445.申请指定遗产管理人（非讼）
- 检索口令：遗产管理人＋1145条＋申请指定遗产管理人＋1148条责任＋报酬1149＋445案由

## 争点：继承的放弃与接受（含受遗赠60日）、丧失继承权与宽宥、转继承
- 请求权基础/抗辩规范：民法典第1124条（放弃继承：遗产处理前书面表示；无表示视为接受。受遗赠：知道受遗赠后60日内表示，到期无表示视为放弃）、第1125条（丧失继承权五事由＋第2款宽宥制度＋受遗赠人准用）、第1152条（转继承）
- 构成要件树：
  1. 放弃继承形式：书面（T1_009第33条）；诉讼中口头放弃记入笔录并签名（第34条）；遗产分割后放弃的是所有权而非继承权（第35条）
  2. 放弃无效：致放弃人不能履行法定义务（对父母子女扶养义务等——T1_009第32条；婚姻关系中配偶放弃继承侵害共同财产原则不禁止，但致其不能履行法定扶养义务的除外——T1_006第11条）
  3. 反悔：遗产处理前或诉讼中反悔→法院按具体理由决定承认与否；遗产处理后反悔不予承认（T1_009第36条）；放弃效力溯及继承开始（第37条）
  4. 丧失事由：故意杀害被继承人（既未遂均丧失——T1_009第7条）、为争遗产杀其他继承人、遗弃或虐待情节严重（时间手段后果社会影响——第6条）、伪造篡改隐匿销毁遗嘱情节严重（侵害双缺继承人利益致其生活困难——第9条）、欺诈胁迫妨碍设立变更撤回遗嘱情节严重；第3-5项确有悔改＋被继承人宽恕或事后遗嘱列入→不丧失（第1125条第2款）
  5. 转继承：继承人于分割前死亡未放弃→其应继份转给其继承人，遗嘱另有安排除外（第1152条）
- 法律效果：接受/放弃确定继承主体；丧失继承权的其代位人受限（T1_009第17条）；遗嘱指定由丧失继承权者继承的可确认遗嘱无效（第8条）
- 关键司法解释：继承编解释（一）（T1_009）第6-9、17、32-38、44条；婚姻家庭编解释（二）（法释〔2025〕1号）第11条
- 常见抗辩与反击：债权人对债务人放弃继承 → 主张该放弃无效（不能履行法定义务情形）或以债权人撤销权介入（争议路径，须先固定法定扶养不能）；受遗赠人以"不知遗赠内容"抗辩60日 → 60日自"知道受遗赠后"起算，举证知情时点
- 期间与时效：受遗赠表示期间60日（除斥期间，不中止不中断不延长——第199条参照）；继承纠纷3年
- 案由对应：29.法定继承纠纷之（1）转继承纠纷；32.遗赠纠纷
- 检索口令：放弃继承书面＋受遗赠60日＋丧失继承权宽宥＋1125＋转继承＋放弃继承损害债权人

## 争点：限定继承与遗产债务清偿（被继承人债务清偿纠纷）
- 请求权基础/抗辩规范：民法典第1161条（以所得遗产实际价值为限清偿；自愿偿还不在此限；放弃继承的可不负清偿责任）、第1159条（分割遗产应先缴税款债务，但须为双缺继承人保留必要遗产）、第1162条（执行遗赠不得妨碍清偿税款债务）、第1163条（法定继承人先偿，超出部分由遗嘱继承人和受遗赠人按比例以所得遗产清偿）
- 构成要件树：
  1. 债务真实性与属被继承人个人债务（夫妻共同债务先按第1064条区分）
  2. 遗产实际价值范围（遗产清单＋析产：配偶一半先分第1153条）
  3. 清偿顺序：税款债务优先于遗赠；必留份优先于清偿（第1159条但书）
  4. 混合继承场景：先法定继承人清偿，超出遗产价值部分遗嘱继承人、受遗赠人按比例（第1163条）
- 法律效果：限定责任；债权人可诉请继承人在遗产范围内清偿；放弃继承者不列为责任主体（T1_009第44条后段）
- 关键司法解释：继承编解释（一）（T1_009）第44条；执行异议之诉解释（法释〔2025〕10号）第1条、第2条衔接（遗产被执行的案外人异议路径另册）
- 常见抗辩与反击：继承人以"未实际取得遗产"抗辩 → 遗产在其控制范围内仍应在"所得实际价值"内担责；债权人主张突破限定继承 → 须证明继承人隐匿、混同遗产（第1148条管理人责任并行）
- 期间与时效：债权请求适用3年；遗产处理完毕后债权人另行起诉继承人受偿的请求受实际价值限制
- 案由对应：31.被继承人债务清偿纠纷
- 检索口令：限定继承＋1161＋遗产实际价值＋被继承人债务清偿＋遗赠不妨碍清偿＋必留份优先

## 争点：遗赠与遗赠扶养协议效力（含受遗赠人权利保护）
- 请求权基础/抗辩规范：民法典第1133条第3款（遗赠给国家、集体或法定继承人以外组织个人）、第1124条第2款（60日接受表示）、第1144条（附义务遗赠）、第1158条（遗赠扶养协议：继承人以外组织或个人承担生养死葬义务享有受遗赠权）
- 构成要件树：
  1. 受遗赠人须非法定继承人（配偶子女父母等列为"继承"而非"遗赠"）
  2. 受遗赠权丧失：受遗赠人有第1125条第1款行为的丧失受遗赠权（第1125条第3款）
  3. 协议解除：扶养人无正当理由不履行致解除→无受遗赠权且供养费用一般不补偿；遗赠人无正当理由不履行致解除→偿还已付供养费用（T1_009第40条）
  4. 与遗嘱冲突：遗赠扶养协议优先（第1123条；T1_009第3条）
- 法律效果：受遗赠人接受表示后即取得转继承性权利（表示接受后分割前死亡→权利转移其继承人——T1_009第38条）；放弃遗赠部分转法定继承（第1154条第1项）
- 关键司法解释：继承编解释（一）（T1_009）第3、38、40条；总则编解释（T1_004）第2条（遗赠扶养协议解释可参考习惯）
- 常见抗辩与反击：法定继承人以"集体组织未实际扶养"否定协议 → 举证生养死葬义务履行记录；以"60日已过"抗辩 → 核"知道受遗赠"的起算点
- 期间与时效：接受遗赠60日为除斥期间；遗赠履行请求3年
- 案由对应：32.遗赠纠纷；33.遗赠扶养协议纠纷
- 检索口令：遗赠扶养协议优先＋60日接受＋丧失受遗赠权＋解除协议供养费用＋1158

## 争点：遗产分割方法、胎儿预留份与隐匿遗产的少分
- 请求权基础/抗辩规范：民法典第1132条（协商处理，协商不成调解或诉讼）、第1153条（先析出配偶及他人财产）、第1155条（胎儿份额保留；娩出为死体按法定继承）、第1156条（有利生产生活不损害效用；折价、补偿、共有）
- 构成要件树：
  1. 析产先行：夫妻共同财产先分一半（第1153条第1款）
  2. 胎儿预留：应留未留→从继承人所继承遗产中扣回；娩出后死亡→由其继承人继承；死体→由被继承人继承人继承（T1_009第31条）
  3. 分割方法：房屋、生产资料与特定职业财产按使用效益与实际需要处理（T1_009第42条）；不宜分割的折价补偿共有（第1156条第2款）
  4. 隐匿侵吞争抢遗产→法院可酌情减少其应继份额（T1_009第43条）
  5. 应保留未知继承人份额并确定保管人（T1_009第30条）
- 法律效果：分割判决；管理人报告义务支撑份额查明
- 关键司法解释：继承编解释（一）（T1_009）第30、31、42、43条；总则编解释（T1_004）第4条（涉及胎儿利益保护父母可作为法定代理人主张——遗产继承、接受赠与）
- 常见抗辩与反击：以"遗产权属未确认"拒绝分割 → 继承纠纷中可一并确认（第1154条未处分部分法定继承）；争抢遗产者主张均分 → 第1130条第3、4款与T1_009第43条调减
- 期间与时效：分割请求在遗产共有状态下不受时效限制；侵权性侵占按3年
- 案由对应：29、30、32继承案由项下；涉共有物分割规则参照
- 检索口令：遗产分割＋胎儿预留份＋1155＋扣回＋折价补偿共有＋隐匿遗产少分＋先析产后继承
